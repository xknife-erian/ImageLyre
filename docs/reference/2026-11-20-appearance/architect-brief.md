## 0 一句话

设计侧已经把「长什么样、怎么选中、怎么报错」定成一套可执行的值；今晚只需要架构确认这些值怎么落到 Avalonia，不需要再讨论审美方向。

## 1 五个决定（已经拍板，不再开放讨论）

| Key | 决定 |
| :--- | :--- |
| `theme` | 亮 30 / 暗 31，同结构、同字段、同状态，只换颜色与材质 |
| `type` | 四档 20 / 16 / 13 / 11；中文只有 400，最低 11 |
| `space` | 4px 基线、六级间距；右栏 400，紧凑密度 12 / 12 |
| `state` | 五态五通道：当前沿形线、选中轴轨、焦点下划线、悬停只换底、编辑光标 |
| `control` | 按钮三档、二元选择没有开关、表格一轨一线、signal 只做线 |

## 2 三条边界

1. **设计负责**：字体家族意图、四档字号与行高、间距与区域尺寸、18 个语义色、五态语法、控件尺寸与状态、验收语言。
2. **架构负责**：Avalonia 资源键与类型、字体回退、AtomUI 令牌钉死、应用内缩放机制、控件模板覆盖、跨平台实测与验收脚本。
3. **不互相越界**：设计不改资源键与 XAML；架构不改设计值。冲突时以 `typography.md` 2.0、`spacing.md`、`color-tokens.md` 1.3、`state-model.md`、`controls.md` 1.1 为准，回写 `typography-avalonia.md`。

## 3 六个需要架构确认的问题

| # | 问题 | 为什么现在要定 |
| :--- | :--- | :--- |
| Q1 | 资源键是否统一 `Lyre.*` 前缀，放在 `ImageLyre.Themes`？ | 决定设计与实现引用同一套名字 |
| Q2 | 字体回退是否走 `FontManagerOptions.FontFallbacks`？ | CSS 栈在 Avalonia 不成立；中文落字靠回退表 |
| Q3 | AtomUI 的 10 个字号位在哪一层钉死？ | 不钉就必然出现第九档字号 |
| Q4 | 应用内 100–200% 缩放是重算令牌，还是整树变换？ | 整树变换会让 200% 的字发虚 |
| Q5 | 验收用 `Avalonia.Headless` 截图，还是真机手工？ | 决定「遮色、灰度、200%」能不能自动跑 |
| Q6 | `warn.bg` / `warn.line` 由谁补进颜色表？ | 八态里缺校准黄条是全表唯一无 token 的色 |

## 4 五个已知的坑（都是实测或踩过的）

1. **中文没有中间字重**：YaHei 请求 500 落 400、600 落 700；中文层级只能靠字号与色层。
2. **等宽族没有汉字**：Cascadia Mono、Consolas 都取不到「中」；数字列混入中文即错位。
3. **AtomUI 会多出字号**：全局 10 个字号位加控件级令牌；必须逐个钉进四档。
4. **10px 在 125% 系统缩放下是 12.5 物理像素**：所以中文最低 11，10 只给拉丁与数字。
5. **开关与焦点框已被删除**：不要实现轨道旋钮，不要把焦点画成外框；这两条是产品口径，不是风格偏好。

## 5 未决与风险

- **仓内编译不了**：SDK 10.0.404、`ImageLyre.App` 未还原、`Cangming.Toolkit.Avalonias.AtomUI` 无缓存；所有运行期结论仍是待实测。
- **`typography-avalonia.md` 仍是八档映射**：需要架构按四档更新，当前只作参考，不是契约。
- **设计稿是 HTML 参照**：不是实现，像素不能照抄；以 token 与 DIP 为准。
- **收工快照未推送**：本地 `854e087`，远端 `bca840d`；架构看仓库时可能看不到今晚的小结与八态修正。
