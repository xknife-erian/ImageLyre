# ImageLyre 主界面规格

| 版本 | 日期 | 状态 | 作者 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 0.1 | 2026-11-20 | 历史 | lukan | 主界面全部细节：窗口、文档、空/载/错三态、菜单、命令、Agent、设置、历史、导出、批次、状态栏、键盘、光标、右键、中英文 |
| 0.2 | 2026-11-25 | 现行 | lukan | 状态栏分隔线的“上下 6”补注来源（密集读数带例外）；状态栏高度由 `spacing.md` 1.1 统一为 28 |

## 0 读法

- 视觉基准：稿 30（亮）/ 31（暗）；排印、间距、颜色、状态、控件分别以 `typography.md` 2.0、`spacing.md`、`color-tokens.md` 1.3、`state-model.md`、`controls.md` 1.1 为准。
- 本文只回答「主界面上有什么、在哪、什么状态下长什么样、键盘怎么走」；不写实现。
- 所有值用 `key = value` 表述，key 可被设计与实现直接引用。

## 1 窗口壳

| Key | 值 | 说明 |
| :--- | :--- | :--- |
| `window.default` | 1440 × 900 | 首次启动，居中，屏幕不足时按 90% 收缩 |
| `window.min` | 1120 × 720 | 低于此尺寸不缩字，改为折叠批次条、收窄右栏 |
| `window.max` | 屏幕可用区 | 支持最大化、贴边、多显示器 |
| `window.title` | `ImageLyre — <文件名>` | 未保存加 `•`；未打开为 `ImageLyre` |
| `window.theme` | 亮 / 暗 / 跟随系统 | 标题栏右端切换，不重启 |
| `window.language` | 中 / EN | 标题栏右端切换，不重启 |
| `window.zoom` | 100% / 125% / 150% / 200% | 设置内切换；图像缩放独立 |
| `window.multi` | 单窗口多文档 | 见 §2；不做多开进程 |

标题栏从左到右：应用名、文件名、已保存状态、Agent 就绪、语言、主题、设置、窗口控制；右侧总宽不超过 520，125% 下自动隐藏文字保留图标。

## 2 文档模型与标签

| Key | 值 | 说明 |
| :--- | :--- | :--- |
| `doc.open` | 单文档 / 多文档 | 同窗口多文档；第二个文档起出现标签条 |
| `doc.tabs.height` | 28 | 单文档时隐藏，不占高度 |
| `doc.tabs.max` | 12 | 超出后标签条横向滚动，不缩字 |
| `doc.tab.state` | 默认 / 悬停 / 当前 / 脏 / 只读 / 错误 | 当前 = 底 + 下沿 2px 信号线 |
| `doc.close` | Ctrl+W / 中键 / 标签 × | 脏文档先存撤销点，不弹确认框 |
| `doc.switch` | Ctrl+Tab / Ctrl+Shift+Tab / 点击 | 切换不重建画布 |
| `doc.new` | Ctrl+O / 拖入 / 最近文件 | 同一窗口新标签，不抢当前 |

- 关闭最后一个文档回到空态，不退出应用。
- 文档顺序 = 打开顺序；拖拽标签可重排。
- 标签只显示文件名，完整路径在工具提示与档案身份段。

## 3 空态

| Key | 值 | 说明 |
| :--- | :--- | :--- |
| `empty.title` | 把图放上去 | 一屏一句，不写欢迎语 |
| `empty.drop` | 整窗可拖入 | 拖入时画布区出现 1px 虚线框 + 提示 |
| `empty.actions` | 打开文件 / 打开示例 / 最近文件 | 三个入口，竖排，间距 8 |
| `empty.recent` | 最多 8 条 | 显示文件名、校准、时间；点击打开 |
| `empty.sample` | 3 张内置示例 | 带校准 16 位、无校准 8 位、多通道各一 |
| `empty.footer` | 版本与构建号 | 右下角，11px T3 |

不做欢迎页、不做强制向导、不要求先配置。

## 4 加载态

| Key | 值 | 说明 |
| :--- | :--- | :--- |
| `loading.canvas` | 骨架 + 进度条 | 画布区显示文件尺寸与已解码百分比 |
| `loading.status` | 状态栏左侧 | 「正在打开 sample.tif · 64%」 |
| `loading.cancel` | Esc / 进度条右侧取消 | 取消后回到空态或上一文档 |
| `loading.background` | 超过 300ms 才显示 | 快文件不闪 |
| `loading.partial` | 可先显示首帧 | 后续帧继续解码，画布可操作 |

## 5 错误与边界

| Key | 值 | 说明 |
| :--- | :--- | :--- |
| `error.banner` | 画布上方 32px 内联条 | 文本 + 重试 + 详情；不弹窗 |
| `error.kinds` | 打不开 / 解码失败 / 缺校准 / ROI 越界 / 只读 / 插件崩溃 | 六类各有文案与动作 |
| `error.missingCalibration` | 黄色提示 + 「设置比例尺」 | 仍可测量像素，物理单位标 `px` |
| `error.roiOutOfBounds` | 顶点拖出边界时吸附 | 不报错，状态栏提示「已贴边」 |
| `error.readOnly` | 标题加「只读」 | 导出可用，编辑禁用 |
| `error.retry` | 重试一次 / 换文件 | 重试不丢当前视图 |

错误文案必须回答：发生了什么、影响什么、怎么退回去。

## 6 菜单

| 菜单 | 条目 | 快捷键 | 禁用条件 |
| :--- | :--- | :--- | :--- |
| 文件 | 打开、最近文件、关闭、导出 CSV、设置、退出 | Ctrl+O / Ctrl+W / Ctrl+E | 未打开图时导出禁用 |
| 编辑 | 撤销、重做、复制、粘贴、删除选区 | Ctrl+Z / Ctrl+Y | 无历史时禁用 |
| 图像 | 类型（8/16/32/RGB）、校准、属性、复制图像 | — | 未打开图时禁用 |
| 分析 | 测量、测量设置、直方图、像素探针 | Ctrl+M | 无 ROI 时测量禁用 |
| 插件 | 插件中心、重新加载插件、已安装列表 | — | 无插件时列表为空 |
| 帮助 | ImageJ 对照表、键盘映射、诊断包、关于 | F1 | 始终可用 |

- 菜单项高度 28，左右 12；快捷键右对齐 11 mono T3。
- 子菜单在右侧展开；不在菜单里放开关，二元项用勾选。
- 菜单栏在 125% 下保持 32 高，文字不缩。

## 8 Agent

| Key | 值 | 说明 |
| :--- | :--- | :--- |
| `agent.presence` | 标题栏「Agent 就绪 · 只读」 | 常驻状态，不占画布 |
| `agent.drawer` | 右栏切换「档案 / Agent」 | 宽 400，与档案同位置，不覆盖画布 |
| `agent.context` | 当前文件、ROI、校准、六项 | 结构化摘要，不是聊天记录 |
| `agent.capabilities` | 读：图像、ROI、校准、结果；写：无 | 写操作必须显式确认 |
| `agent.proposal` | 提案卡：做什么、为什么、影响什么、撤销 | 每条可接受 / 忽略 |
| `agent.flow` | 「把这次分析变成流程」 | 生成可复用步骤，不自动执行 |

Agent 不是聊天侧栏：没有头像、没有气泡、没有打字动画；它给的是可审阅的提案。

## 17 验收清单

1. 空态三入口可用，拖入有反馈，最近文件可打开。
2. 打开大图有进度、可取消，取消后无残留。
3. 六类错误都是内联条，无弹窗，文案含原因与退路。
4. 多文档标签出现、切换、关闭、脏标记正确；关闭最后一个回空态。
5. 六个菜单条目与禁用条件正确，快捷键与菜单一致。
6. Ctrl+K 可搜中英文，四个分区齐全，Agent 区可读。
7. Agent 抽屉只给提案，不自动执行，写操作需确认。
8. 设置五个分区可用，改变即时生效，无重启。
9. 历史列表、对比、回退、前进正确，回退留痕。
10. 导出抽屉不遮右栏，预览与 CSV 一致，sidecar 同名。
11. 批次条可收起，状态四态正确，当前卡左沿 2px。
12. 状态栏不截断数字，保存状态可点开历史。
13. 键盘全路径可完成一次测量；焦点只显示下划线。
14. 光标在画布、平移、ROI、顶点、只读五种场景正确。
15. 四个右键菜单条目与禁用条件正确。
16. 中英文切换即时生效，无混用、无截断、数字不变。
17. 125% 与 200% 缩放下不重叠、不截断，五段仍可达。
18. 亮暗两套下所有状态仍可区分，灰度后仍成立。
19. 所有按钮与菜单项都有快捷键或可搜索路径。
20. 关闭窗口前自动保存，重开恢复最后一笔有效操作。
