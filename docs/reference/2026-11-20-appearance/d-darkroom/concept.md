# 暗房 · Darkroom

**一句话直觉**：关掉顶灯，只留一盏观片灯——样本亮着，界面沉下去。

**布局**：1440×900 桌面窗，标题栏、菜单栏、窄工具条、状态栏俱全。样本满幅，四边渐隐进机身；42px 测量参数条贴着画布下缘，改完即算；Results 压在底部，是一张六行读数纸带。

**色彩与材质**：机身近黑偏暖，文字低饱和暖白 #e8e2d6；全屏只有一个冷信号 #8ec6d7，只给选中与运行。样本是唯一亮面：中心被一束暖光托住，向边缘落进黑里。层次靠明度、光晕与留白，不靠描边与投影。质感像哑光玻璃与纸。

**字体与数字**：界面用系统无衬线 12px，数字用等宽 12px；数值右对齐，单位缩小变暗，一列能竖着扫。

**动效**：只有灯在呼吸，十一秒一轮，幅度极轻；实时点慢脉冲。无扫描线、无发光边框、无装饰网格。

**取舍**：放弃浅色默认、浮层面板、卡片与 HUD 框线；不对工具条加文字；ROI 只留一条细线、四个手柄与一个标签，不做发光框。

**最容易被误认成**：一台暗房观片灯，或医学影像阅片器。
