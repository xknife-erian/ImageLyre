# 观片灯

**名字**：观片灯

**一句话直觉**：暗房里的一台观片灯——四周退成灰，只有样本那一格亮着，读数像刻度盘。

**布局**：标题栏、菜单栏、左侧窄工具轨、中央画布、画布下沿的参数条、贴底的 Results 纸带、状态栏。画布占主体，面板贴边不悬浮；参数在画布边改，数字当场变，不弹窗。

**色彩与材质**：暖中性灰阶，无纯白纯黑，层次靠明度与 1px 细缝。全屏一处琥珀色，只给选中、警告、运行中。无圆角、无投影、无玻璃；按键是平的，用一像素亮边与暗边立起来。浅色是台面，深色是暗房。

**字体与数字**：系统字体，标签小、字距松；数字等宽、右对齐、列宽固定，单位小一号、降一档灰，六行能竖着扫。

**动效**：只解释空间。面板从所属的边出现，颜色过渡 160ms，不弹跳。

**取舍**：放弃彩色工具图标、浮动卡片、右侧检查器与装饰性图表；强调色只留一处，代价是警告与选中同色，只能靠文字与位置区分。

**最容易被误认成什么**：某台显微镜或相机的采集上位机——太像仪器面板，少了“分析”的视觉暗示。
