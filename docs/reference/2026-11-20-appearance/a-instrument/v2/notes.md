# 读数签

**布局逻辑**：一扇窗，一块玻璃。窗框只留文件名、16-bit、0.5 µm/px、主题与窗控；玻璃上三件实物：工具转塔、读数签、底沿读数。样本占满窗内。

**去掉了什么**：菜单、工具栏、Results 面板、状态栏。六个数不是表格，是一张用细线拴在选区上的纸签；脚上是撤销与导出 CSV。参数是签内的单位档位，一拨，Area 与 Perimeter 当场重印。

**为什么只属于我**：仪器不该喊。纸签有夹子、撕线、档位，没有圆角、投影与玻璃；除琥珀外全是灰阶；数字等宽右对齐，单位退后。六个顶点可直接拖，选中的是实心琥珀。

**ImageJ 老用户**：Results、ROI 03、Analyze › Measure 都在；Ctrl+K 命令面板沿用旧菜单名；Ctrl+Z 与导出 CSV 在签脚；多边形仍是 P。

**最大风险**：读数签压住样本右侧，且大图上"结果跟着选区走"可能挡手；只认固定面板的人会把它当浮层。
