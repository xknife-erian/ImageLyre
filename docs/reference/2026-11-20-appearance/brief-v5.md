# 外观第五轮：一套骨架，两件衣服

| 版本 | 日期 | 状态 | 作者 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 0.1 | 2026-11-20 | 现行 | lukan | 按 20/19 审查的 P0 收口：统一骨架，补语言、Agent、版本与自动保存入口；21 亮、22 暗 |

## 1 这一轮只做一件事

把 20 与 19 变成同一套骨架的两件衣服：结构、字段、入口、顺序完全一致，只有颜色、明度与材质不同。顺手把审查里的三个入口补齐，避免两版各改一次又漂移。

## 2 骨架（两版必须逐项一致）

1. **标题栏**：应用名 + 文件名 + 已保存状态（如「已保存 10:42」）+ 语言（中/EN）+ 主题 + 设置 + 窗控。
2. **菜单栏**：File、Edit、Image、Analyze、Plugins、Help；Analyze 下要能看见 Measure，Image 下要能看见 Type。
3. **左缘工具轨**：指针、矩形、多边形、手、缩放；图标加键位提示，不只用字母。
4. **画布**：最大；下沿常驻坐标、像素值、缩放、校准。
5. **右栏一列「标本档案」**，自上而下固定五段：
   - 身份：样本号、批次、来源、染色、采集、复核、文件、位深、校准；
   - 测量：标题写「测量 / Results」，六项读数第一屏，下面一行「台账 · 6 个 ROI」；
   - 参数：单位、小数位、阈值、自动重算，就地改；
   - 溯源：默认一行摘要（校准链 + 哈希前八位 + 插件版本），点开才是全部；
   - 操作：撤销、导出 CSV（含 sidecar）、历史版本。
6. **底部批次条**：同批样本缩略图，可收起，标题写明「同批」。
7. **命令面板**：Ctrl K，命令之外必须有 Agent 区：说明它能看见当前图、ROI、校准与六个数，并写明读什么、写什么。
8. **版本与自动保存**：标题栏的已保存状态点开，进入历史版本、对比、回退。

## 3 两版

- **稿 21（亮）**：从稿 20 长出来，纸白、朱红、细线；
- **稿 22（暗）**：从稿 19 长出来，深色、等宽、琥珀。

两版都必须有浅色与深色，但本轮只画各自的主态：21 画亮、22 画暗；结构必须能一一对上。

## 4 仍然要守住

桌面软件、Windows 首发、零模态、画布优先、单一信号色、无圆角卡片与投影、与 ImageJ 的渊源。

## 5 验收

把两版并排，遮住颜色，逐项对：标题栏、菜单、工具轨、档案五段、批次条、命令面板、已保存状态。对不上的地方就是缺陷。
