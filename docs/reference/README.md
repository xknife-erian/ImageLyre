# reference/ —— 外部参考资料

本目录承接**来自外部的参考资料与可查阅的事实清单**，回答“原文是怎么说的”，例如厂商设备手册、第三方协议文档、芯片寄存器表、标准原文。它与其它目录最大的差别是：这里存放的**不是本团队自己的结论**，因此表格与正文里的说法以来源原文为准，我们的解释与取舍放进 `analysis/`，定型结论放进 `spec/` 或 `adr/`。

## 命名与存放

外部资料**保留原文件名不改名**（如 `IDS830ABS低压直流伺服用户手册V1.0.docx`），因为文件名是来源方的标识，改名会让别人对不上号；项目自建的查阅清单或摘录用 `<主题-slug>.md`。本目录**不按用户名分目录**，属于项目共有。

## 必备章节（项目自建文档）

来源与版本、适用范围、条目正文或索引；完成判据是每条事实都能对回原始出处（手册页、协议章节）。外部原件本身不要求改写结构，但应在本目录的自建清单里登记来源、版本与适用范围。

## 注意

体积大且与具体版本绑定的原件（安装包、固件、厂商工具）不进本目录，只登记来源与获取方式；密钥、授权码与账号信息一律不得写入。
