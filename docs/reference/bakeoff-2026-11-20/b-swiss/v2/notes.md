# Plate 01

**布局逻辑**：整窗是纸，无面板。页眉即 running head：书名、文件名、菜单；右端收主题、撤销、导出。左边整幅图版，右边六行 Results 页边账；图下一行图注收坐标、像素、缩放、校准，再一行收工具与顶点。红 1px 引线从顶点 P3 直通 AREA，把选区与数字接起。

**去掉了什么**：标题栏底色、工具条、底部结果表、状态栏、边框与投影；菜单不再是 chrome，结果从横表变竖账。

**为什么只属于我的风格**：8pt 网格、字号阶比、大写小标宽字距、等宽右对齐、单位退后、黑白灰加一点朱红；层次只靠留白与 1px 线。

**ImageJ 老用户**：菜单名不动，Analyze 与 Results 都在；六项原名保留；ROI 仍是多边形与顶点。

**最大风险**：可能先被读成一张精良 PDF 或论文图版，而不是可点的软件；工具参数也安静。
