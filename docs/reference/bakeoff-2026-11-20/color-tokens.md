## 0 三条前提

1. **同构换值。** 明暗两套 token 一一对应：数量相同、语义相同、位置相同，只换色值；没有「暗色少一层灰」。
2. **颜色只做层级辅助。** 灰度截图后主次仍成立；颜色不承担唯一信息，也不代替字号、字重与留白。
3. **一屏只有一处「当前」。** `signal` 只标当前 ROI 与运行中，其余一律中性；没有第二个强调色。

## 1 命名

| 前缀 | 管什么 | 例 |
| :--- | :--- | :--- |
| `surface.*` | 底 | `surface.panel` |
| `line.*` | 1px 线 | `line.border` |
| `text.*` | 文字层 | `text.t2` |
| `signal.*` | 当前与运行 | `signal.active` |
| `state.*` | 交互状态 | `state.selected.bg` |
| `canvas.*` | 图像叠加，不随主题 | `canvas.ink` |

- 名字说用途，不说深浅：没有 `gray-200`、`tint-2`、`primary-500`。
- 一个 token 只干一件事；同一个值有两种语义时给两个名字（见 `signal.running`）。
- 界面里不出现本表之外的色值，也不用十六进制直接写进控件。

## 2 表面 surface

| Token | 亮 | 暗 | 用途 | T1 在亮底 | T1 在暗底 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `surface.window` | `#F5F6F8` | `#15171A` | 窗口底：标题栏、菜单、状态栏、工具轨 | 16.76:1 | 15.14:1 |
| `surface.panel` | `#FFFFFF` | `#1C1F23` | 面板、列表、浮层 | 18.13:1 | 13.95:1 |
| `surface.canvas` | `#E8EAED` | `#0D0F11` | 画布底：图像四周的台面 | 15.04:1 | 16.19:1 |
| `surface.input` | `#FFFFFF` | `#121417` | 输入框、下拉、数值格的底 | 18.13:1 | 15.56:1 |
| `surface.hover` | `#EAEDF0` | `#292E34` | 悬停底（替换原底，不叠加） | 15.42:1 | 11.54:1 |

- 五个面全部中性，不带暖黄：窗口是浅灰白，面板与输入是纯白，画布比窗口深一档，悬停是浅灰。
- 面板与输入同取纯白，输入只靠 `line.border` 界定；不用内阴影、不用凹陷装饰、不用底色区分。
- 画布底两套都最深：图像是唯一被照亮的东西，台面退到它后面。
- 悬停底是实色，替换而非叠加；只用于窗口与面板内的行、按钮、工具格，不用于画布。

## 3 线 line

| Token | 亮 | 暗 | 用途 | 对 `surface.panel`（亮 / 暗） |
| :--- | :--- | :--- | :--- | :--- |
| `line.divider` | `#DFE2E6` | `#2A2E33` | 同级分隔：行与行、段与段 | 1.30:1 / 1.21:1 |
| `line.border` | `#C2C7CD` | `#3C4249` | 控件、面板、输入框的边框 | 1.70:1 / 1.63:1 |
| `line.focus` | `#B83A24` | `#D89A4A` | 键盘焦点下划线 | 5.72:1 / 6.81:1 |

- 线一律中性灰：没有暖褐，没有偏黄的描边。
- 只有 1px：没有 2px 分隔线，没有投影，没有内阴影。
- 分隔线只分隔同级；跨级（面板 vs 窗口）一律用 `line.border` 画外框。
- 焦点线贴控件底边，1px：它是下划线，不是外框、不是光晕；整行、整卡都不套框。
- 焦点线取 `signal`：焦点也是「当前」，不为它新增强调色。
- 焦点环按非文本要求 ≥3:1（实测 5.72 / 6.81）。

## 4 文字 text

| Token | 亮 | 暗 | 用途 | 面板（亮 / 暗） | 最弱合法底（亮 / 暗） |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `text.t1` | `#141619` | `#E9ECEF` | 正文、读数、菜单、标题 | 18.13 / 13.95 | 14.45 / 10.73（选中底） |
| `text.t2` | `#4C5259` | `#B5BBC2` | 字段值、状态、单位 | 7.90 / 8.55 | 6.30 / 6.57（选中底） |
| `text.t3` | `#6A717A` | `#8C939B` | 标签、表头、脚注、哈希 | 4.93 / 5.33 | 3.93 / 4.10（选中底） |
| `text.disabled` | `#7B828A` | `#7E858D` | 不可用 | 3.89 / 4.43 | 3.10 / 3.41（选中底） |

- T1 是近黑中性，T2 与 T3 是冷灰；没有暖褐，也没有偏绿偏紫的灰。
- 正文与读数 ≥4.5:1（实测最低 6.30）；弱化文字 ≥3:1（最低 3.93）；禁用 ≥3:1（最低 3.10）。
- 与排印 2.0 的关系：1.0 用过该节 §8 的暖灰参考值；1.1 按业主反馈改为中性冷灰，全部高于该节声明的底线（正文 4.5、弱化 3）。`typography.md` 不改，落地以本表为准。
- 不设 T4：更弱的信息靠位置与留白，不靠第四层灰。
- 禁用文字仍要完整可读，不截断、不省略；变灰只是提示，不是信息本身。

## 5 信号 signal

| Token | 亮 | 暗 | 用途 | 面板（亮 / 暗） | 窗口（亮 / 暗） | 画布（亮 / 暗） |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `signal.active` | `#B83A24` | `#D89A4A` | 当前 ROI、当前行、当前页签 | 5.72 / 6.81 | 5.29 / 7.39 | 4.75 / 7.90 |
| `signal.running` | `#B83A24` | `#D89A4A` | 运行中、正在测量 | 同上 | 同上 | — |

- 与 1.0 相同：亮色橙红，暗色同族提亮；没有新增第二种强调色。
- 只做 2px 标与线：当前 ROI 的 2px 边、当前项的 2px 标（列表贴左、页签贴顶）、运行中的 6px 点或图标描边。
- 不做任何填充：不填充整行、不做按钮底色、不做选中块、不做图表面积；选中态也不靠 signal 铺底。
- 不做正文：需要文字时用 T1；`signal` 只做标记。
- 同一时刻「当前选区」与「运行中」可并存，用形状区分（线 / 点），不增设第二档色。
- 亮色橙红压在图上不足 3:1，画布上的 ROI 必须加 1px `canvas.edge` 外沿（见 §8）。

## 6 状态四组

### 6.1 状态专用底

| Token | 亮 | 暗 | 用途 | 落在其上的文字对比（亮 / 暗） |
| :--- | :--- | :--- | :--- | :--- |
| `state.selected.bg` | `#E2E6EA` | `#2E333A` | 选中行、选中项、当前文档页签 | T1 14.45 / 10.73；T3 3.93 / 4.10 |
| `state.disabled.bg` | `#F1F3F5` | `#1A1D21` | 禁用按钮、禁用输入 | 禁用字 3.49 / 4.53 |

### 6.2 四组状态

| 状态 | 亮 | 暗 | 规约 |
| :--- | :--- | :--- | :--- |
| 悬停 hover | 底 `surface.hover`；线、字不变 | 底 `surface.hover`；线、字不变 | 只换底，不换字重 |
| 选中 selected | 底 `state.selected.bg` + 2px `signal.active` 标；字仍 `text.t1` | 底 `state.selected.bg` + 2px `signal.active` 标；字仍 `text.t1` | 中性底 + 标，不反白；**线随轴**：横向控件放下沿，纵向列表放左沿 |
| 焦点 focus | 线 `line.focus`，1px，贴底边 | 线 `line.focus`，1px，贴底边 | 只换线，不换底；不套外框 |
| 禁用 disabled | 底 `state.disabled.bg`；线 `line.divider`；字 `text.disabled` | 底 `state.disabled.bg`；线 `line.divider`；字 `text.disabled` | 可读，不承载唯一信息 |

- **选中不反白**：选中、当前工具、当前页签一律「一档中性底 + 2px 信号标 + T1 文字」，不使用深色实底配浅色字，也不用 signal 铺底。暗色下选中底比面板亮一档（不是黑块）。
- **选中标**：贴在控件自身轴向的边上——横向控件贴下沿，纵向列表贴左沿；多选时每行都有标，信号不因数量增加而增强，也不填充整块。
- **悬停**：行、按钮、工具格、下拉项共用同一个底；不出现第二种悬停色。禁用项没有悬停态。
- **焦点**：只在键盘路径上出现；输入框聚焦时底边换 `line.focus`、底不变；鼠标点击不保留焦点。焦点与选中可同时存在，分别用下划线与轨，互不覆盖。

### 6.3 信号标随轴

| 控件形状 | 例子 | 信号标位置 |
| :--- | :--- | :--- |
| 横向 | 工具栏格、语言切换、主题切换、单位分段、小数位分段、页签 | 下沿 2px |
| 纵向 | 批次当前卡、档案行、列表项 | 左沿 2px |
| 画面对象 | 当前 ROI | 沿形 2px 描边，不参与控件规则 |

- 同一屏可以同时出现下沿与左沿，它们不是两套语言，而是同一条规则在不同轴上的表现。
- 不允许同一个控件既放下沿又放左沿；不允许把标放在上沿或右沿。
- 标只画 2px，不随字号或缩放变粗；缩放后仍是 2 物理像素的线，不是 2×缩放。
- **禁用**：底、线、字三层同时降级；鼠标不出现悬停底。禁用不能是唯一路径——该动作必须在别处有可读说明或替代入口，否则不做禁用，改为点击后说明原因。
- **四组状态里没有任何深色填充块**：亮色下没有黑底，暗色下没有比面板更深的实心块（画布底与画布上的图像除外）。

## 8 画布叠加

图像本身不随主题切换，所以压在图上的一对颜色两套同值，不参与明暗切换。

| Token | 两套同值 | 用途 | 对比 |
| :--- | :--- | :--- | :--- |
| `canvas.ink` | `#F5F7FA` | 比例尺、坐标与像素值标签 | 对 `canvas.edge` 18.14:1 |
| `canvas.edge` | `#0B0D0F` | 叠加件的 1px 外沿 | — |

- 比例尺与标签用 `canvas.ink`；需要压住亮图时加实底块 + 1px `canvas.edge` 轮廓，不用半透明遮罩、不用模糊。
- 画布上的 ROI 用 `signal.active`，外压 1px `canvas.edge`，保证任意图都有边界。
- 不做文字描边：需要时用实底块，不用给字加边。

## 9 禁止清单

- 禁止渐变、投影、内阴影、玻璃拟态、模糊、发光。
- 禁止暖黄、米色、暖褐底：表面与线一律中性。
- 禁止深色实底反白：选中、当前工具、当前页签都不做黑底白字或深底浅字。
- 禁止第二强调色：除 `signal` 外不出现饱和色，图表也用灰阶。
- 禁止 `signal` 当填充、当正文、当装饰。
- 禁止颜色作为唯一信息：状态必须另有形状、位置或文字。
- 禁止表外色值；禁止非 1px 的线；禁止用 T3 写正文；禁止用禁用态承载唯一信息。

## 10 验收

1. **取色**：全屏取样，所有色值都能在本表按名查到，没有表外值，没有暖黄残留。
2. **对比度**：正文 ≥4.5、弱化 ≥3、禁用 ≥3、焦点 ≥3，两套都过（见 §7）。
3. **无反白**：选中、当前工具、当前页签都没有深色实底；截图去色后仍能看出选中。
4. **信号**：一屏只有「当前」一件事被 `signal` 标出——当前 ROI（含它在列表里的那一行）与运行中；没有第二处填充、没有第二处线条。
5. **并排**：明暗两套 token 一一对应，没有哪套多一层灰。
6. **放大**：200% 下所有线仍是 1 DIP，没有阴影与光晕。

## 11 边界

- 字号、字重、行高、字距见 `typography.md` 2.0；间距与控件尺寸见 `spacing.md`；本文只定颜色与状态，两个文件都不改动。
- 1.1 只换了色值与反白禁令，不改 token 名单、不改语义、不改状态数量。
- 图像内容、LUT 与伪彩不在本文；画布叠加只定表中的两个值。
- 21 与 22 的现有色值按本表替换：先换表面与线，再换文字，最后接 `signal`；替换不改变结构、字号与间距。
