# 外观竞标第二轮：只给任务，不给位置

| 版本 | 日期 | 状态 | 作者 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 0.1 | 2026-11-20 | 现行 | lukan | 第一轮因限定过死导致骨架雷同；第二轮撤掉位置与形态，只保留必须能完成的事 |

## 1 为什么要重来

第一轮给了「必须出现标题栏、菜单栏、左侧工具条、中央画布、Results、状态栏」，等于把布局也写进了考卷，六版自然长得一样。第二轮只规定用户必须能完成什么，位置、形态、层级、数量全部交给设计师。

## 2 不规定的事

- 有没有标题栏、菜单栏、工具条、Results 面板、状态栏；
- 它们在哪、什么形态、是否常驻、是否浮层、是否可折叠；
- 是否使用命令面板、上下文工具条、抽屉、叠层、边缘手势、双栏或无栏；
- 一个窗口还是可拆分的窗格。

唯一保留的形态约束：它必须是桌面软件的一个窗口，有窗口感，不是网页。

## 3 必须能完成的事

评审按这七条逐一点：

1. 打开一张 16 位、0.5 µm/px 的 TIFF，知道文件名、位深与校准；
2. 在图上画一个多边形 ROI，并能修改顶点；
3. 看到六项测量：面积、均值、标准差、最小、最大、周长；
4. 改一个测量参数（阈值、单位或小数位），不弹窗，结果当场变；
5. 随时知道坐标、像素值、当前缩放与校准；
6. 切换浅色与深色主题；
7. 找得到撤销与导出 CSV。

七条都能完成，但完成它们的东西可以长得完全不像第一轮。

## 4 仍然不动的底线

- 桌面软件，Windows 首发，三端共用设计，不是网页；
- 零模态：参数在画布边上改，不弹窗；
- 画布优先：样本是视觉主角；
- 与 ImageJ 有渊源：老用户五分钟能完成第一次测量，路径要看得见；
- 单文件 HTML，内联 CSS，无 JS、无外链字体与图片。

## 5 评判口径

先看第一眼有没有一个让人记住的动作；再看七条任务能不能找得到；最后看遮住 logo 还认不认得出是同一款产品。不评「哪个好看」。
