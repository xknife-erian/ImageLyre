# C2 · 尺侧

**布局逻辑** 满窗画布只留三样：顶脊（文件名、位深、校准、菜单、撤销、导出）、脚下的 µm 尺（工具五格、校准、游标、缩放、主题、命令）、钉在 ROI 上的读数牌。第一眼是拖顶点：形一动，牌里的 1240.5 当场跳 +12.4。效率靠"就地"：数字长在形上，参数在数字下，坐标跟着探针。

**去掉了什么** 标题栏、菜单栏、左侧工具轨、底部 Results 表、状态栏；Results 收成右缘抽屉标签。

**为什么只属于我的风格** 一种蓝只标选中、活动与实时；读数牌三列两行，等宽数字右对齐、单位降级；工具缩成尺子左端五格，快捷键躺在角标里。

**ImageJ 老用户怎么找到路** 顶上仍是 File/Edit/Image/Analyze/Plugins/Help；右缘写着 Results，拉开就是行；六项测量没改名；比例尺与 µm 校准还在原处。

**最大风险** 满窗画布加浮层，可能被读成看图器而非分析软件；读数钉在 ROI 上，横向比较多个 ROI 要多一步。
