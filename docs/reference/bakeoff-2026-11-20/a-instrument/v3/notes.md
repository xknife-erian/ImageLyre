# 工程台账

**怎么落地**：右栏是台账：文件哈希、校准链、每数推导、插件沙箱、事件日志、命令行，一列排下来。等宽、1px 分栏、无圆角；状态与日志常驻。没有标签页与文件树，日志是结构化事件。

**Lyre 自己的东西**：数字带来路。area = Σpx² × 0.25，perimeter = Σpx × 0.5；单位一换，结果、命令行、trace 三处同时改写，factor 留在台面上。沙箱行给出 measure@1.4.2、net off、fs ro、recipe、seed，可复现。

**ImageJ 老用户**：Results 变成台账里的六行；roi-03、polygon 6 v、Measure 都在；P 仍是多边形；Ctrl+K 可直输旧菜单名（Analyze › Measure）；Ctrl+Z 与 export csv 在台账脚。

**最大风险**：台账密度高，久读会累；命令栏可能被误读成终端；没有固定 Results 面板，老用户要先找。
