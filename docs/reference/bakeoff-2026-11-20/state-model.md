# ImageLyre 交互状态语言

| 版本 | 日期 | 状态 | 作者 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 0.1 | 2026-11-20 | 现行 | lukan | 全局状态语法：五态五通道、叠加优先级、二元选择不用开关、表格用轨与下划线 |

## 0 为什么要有这份东西

按控件逐个补状态，必然长成补丁：开关的旋钮被做成方块，因为「不许圆角」；表格的焦点被套上整行红框，因为「焦点要用线」。每个控件都在局部正确，合起来却互相打架。

状态不是控件的装饰，是同一套语法在不同形状上的投影。先定语法，控件只负责选形状。

## 1 五态五通道

| 状态 | 回答的问题 | 唯一通道 | 长什么样 |
| :--- | :--- | :--- | :--- |
| **当前 current** | 画面里哪个对象在被操作 | 沿形 2px 线 | 当前 ROI 的 2px 描边、当前切片标签的 2px 边 |
| **选中 selected** | 谁被选中、命令将作用于谁 | 轴上的 2px 轨 + 一档中性底 | 横向控件下沿、纵向列表左沿；底比常态深一档 |
| **焦点 focus** | 键盘现在落在哪 | 1px 下划线 | 控件底边一条 1px 线；表格是当前行底边一条线；输入是字段底边一条线 |
| **悬停 hover** | 指针经过谁 | 只换底，不画线 | 一档中性底，无边框、无阴影 |
| **编辑 editing** | 正在输入什么 | 光标 + 1px 下划线 | 文本光标；字段底边一条 1px 线；不画框 |
| **禁用 disabled** | 不可用 | 去掉以上全部 | 字与线降级，仍可读，不承载唯一信息 |

一态一通道：同一状态永远只用一种视觉手段，换控件不换语法。

## 2 叠加与优先级

多个状态可以同时存在，但通道不能互相冒充：

- **编辑 > 焦点 > 选中 > 悬停**：优先级高的画，优先级低的不重复画同一条线。
- 选中 + 焦点：选中画轨（左沿或下沿），焦点画下划线，两者位置不同，可以并存；不允许焦点再画一个框。
- 悬停不参与叠加：只在没有选中、没有焦点时出现。
- 当前（画面对象）独立于控件状态：ROI 的描边不受表格焦点影响。
- 同一元素最多两条线：一条轨（选中）、一条下划线（焦点）；再多就是噪音。

## 3 三条不做

1. **不做整行外框**：焦点是下划线，不是盒子；盒子会把一行数据框成一张卡片。
2. **不做色字**：signal 不做文字色；选中、当前、焦点都不改变文字颜色，只改线与底。
3. **不做填充块**：除 hover 的一档洗底外，不用色块表示状态；选中不反白，当前不铺底。

## 4 二元选择没有开关

桌面分析软件不需要移动端的滑块开关。开关的旋钮无论方圆，都会和复选框抢同一个语义。

二元参数只用三种形式，按场景选：

| 场景 | 形式 | 例子 |
| :--- | :--- | :--- |
| 设置、表单 | 复选框：16px 方框 + 2px 勾 | 显示全部、包含边缘 |
| 菜单 | 勾选标记 | 显示标尺、吸附到像素 |
| 行内参数 | 两段式分段：关 / 开，或 µm² / px² | 自动重算、单位、小数位 |

- 不出现滑块开关；不出现「轨道 + 旋钮」。
- 两段式分段与单位分段共用同一个控件，选中用下沿 2px。
- 复选框是方框，分段是文字格；两者不能长得像。

## 5 表格：一条轨，一条线

| 状态 | 画法 |
| :--- | :--- |
| 悬停 | 行底一档洗色 |
| 选中 | 行首左沿 2px 轨 + 选中底；文字不动 |
| 焦点 | 当前行底边一条 1px 线（从行首贯到行尾），不画单元格框 |
| 编辑 | 单元格内文本光标 + 该单元格底边 1px 线；行仍保持选中轨 |
| 选中 + 焦点 | 左沿轨 + 行底下划线，两条线各司其职 |

下划线是「光标停在这一点」的隐喻，框是「这块被选中」的隐喻；表格里已经用左沿说了选中，焦点就不该再说一遍。

## 6 控件映射

| 控件 | 选中 | 焦点 | 编辑 | 禁用 |
| :--- | :--- | :--- | :--- | :--- |
| 按钮 | 无选中，按下换底 | 下划线 1px | — | 线字降级 |
| 工具格 | 下沿 2px | 下划线 1px | — | 线字降级 |
| 分段 | 下沿 2px | 下划线 1px | — | 线字降级 |
| 复选框 | 2px 勾 + 选中底 | 下划线 1px | — | 无勾，线字降级 |
| 下拉 | 展开项左沿 2px | 关闭时下划线 | — | 线字降级 |
| 输入框 | 文本选区 | 下划线 1px | 光标 + 下划线 | 线字降级 |
| 表格行 | 左沿 2px + 底 | 行底 1px 线 | 单元格光标 + 底 1px | 线字降级 |
| 菜单项 | 左沿 2px | 下划线 1px | — | 线字降级 |

## 7 验收

1. 灰度截图：五态仍可区分，且没有只靠颜色传达的信息。
2. 键盘走一遍：焦点始终是一条下划线，任何位置都不出现外框。
3. 叠加检查：选中 + 焦点最多两条线，且位置不同。
4. 全局搜索：不出现滑块开关；不出现整行边框；不出现 signal 文字。
5. 遮住控件看语义：只看线，能说出谁被选中、谁有焦点。
