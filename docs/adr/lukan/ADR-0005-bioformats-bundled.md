# ADR-0005：BioFormats.NET 随安装包内置

| 项 | 值 |
| :--- | :--- |
| 状态 | Accepted |
| 日期 | 2026-11-18 |
| 作者 | lukan |
| 关联 | `docs/spec/startup-requirements.md` 1.3 §3.2；本决策使基线升为 1.4 |

## 状态

Accepted，2026-11-18 由项目负责人拍板，把 BioFormats.NET 从「可选插件」改为「内置插件、默认启用、可禁用」。

## 背景与约束

厂商私有格式（CZI、LIF、ND2、OIB）是目标用户的主力数据，若首次使用还要先去插件市场安装，断网机房与气隙实验室就无法完成基本工作；而把格式支持做成可选，也让「打开即用」的产品承诺落空。另一方面，BioFormats.NET 体积不小、格式覆盖随版本变化，直接编进主程序会让核心安装包膨胀，也无法单独升级格式支持。

## 决策

BioFormats.NET 以插件形式随安装包分发，默认启用、可在插件管理器中禁用；解码按 ADR-0004 在沙箱进程中执行，瓦片回传给主进程。插件加载失败时降级为标准格式可用，并在启动日志与状态栏给出原因，不得影响主程序启动。安装包为此增加的体积预算不超过 300 MB，超出需重新评估拆分方式。

## 备选方案

- **保持可选插件**：安装包小，但断网环境不可用，否决。
- **编入主程序**：启动快，但无法独立升级、体积不可控、崩溃隔离消失，否决。

## 后果

正面后果是厂商格式开箱可用，离线部署成立，格式支持可随插件独立更新。

负面后果是安装包增大、BioFormats.NET 的许可与依赖需要随版本复核，且沙箱解码链路成为 P0 能力，最小插件宿主必须在 MVP 阶段就存在。基线 §3.2 与 §4 的插件表述同步更新，PRD 的 IO-006 与插件底座优先级据此调整。
