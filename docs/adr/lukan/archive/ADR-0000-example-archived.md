## 原决策摘要

编号采用发布日期形式（如 `ADR-2026-11-18`），使读者无需查阅目录即可判断决策的先后顺序。

## 归档原因

日期形式的编号在一天内产出多份决策时会重复，且无法表达同一主题下的修订次序，因此该形式被 `ADR-<四位序号>-<主题-slug>.md` 取代；尽管决策本身已经失效，其中关于“编号该承载时间还是承载顺序”的论证仍是后续修订的重要参照，故予以存档。
