# guide/ —— 使用与接入指南

本目录承接**面向使用者与接入者的指南**，回答“怎么上手、按什么步骤做”，例如模块使用指南、接入步骤、配置说明、迁移指引。它与 `design/` 的分界是：`design/` 讲系统内部长什么样、边界在哪，`guide/` 只讲使用者该怎么操作；与 `spec/` 的分界是：`spec/` 是可判定的约束，`guide/` 是达成目标的路径。

## 命名约定

`<两位序号>-<主题-slug>.md`，序号在同一批指南内连续（如 `01-基本原理与使用指南.md`、`02-配置与部署.md`），便于读者按顺序阅读。本目录**不按用户名分目录**，属于项目共有。

## 必备章节

适用对象、前置条件、步骤、常见问题；完成判据是读者照着做能完成目标、无需追问。步骤涉及的界面或输出建议配截图，截图放 `docs/assets/` 并在本文件上方登记表登记 `assets/`。

## 与其它目录的关系

设计定型后反推出指南；指南中出现的行为若与实现不一致，以 `design/` 与代码为准并回来修正指南，不要在两处各写一套行为描述。
