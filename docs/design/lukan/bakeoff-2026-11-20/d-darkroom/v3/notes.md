# 暗房 v3 · 记录

**这条道怎么落地**：中性深灰、菜单、文档标签、工具选项栏、居中画布、右侧可停靠面板、底部胶片条——Photoshop 的语法整套搬来。但面板里没有图层：直方图带阈值窗与均值线，拖阈值、改小数，Results 当场变；Info 常驻坐标、像素、缩放、校准。

**Lyre 自己的东西**：直方图不为调色，为阈值；胶片条不是文件列表，是同一批、同一校准的样本；选项栏只放 ROI 工具与顶点状态，不放假滤镜；画布上的 ROI 标签直接写面积。

**ImageJ 老用户**：Results 这个词还在，Analyze 菜单还在，六项同名指标、多边形手柄、0.5 µm/px 都在；打开即测，没有向导。

**最大风险**：太像 Photoshop，可能先被当成修图软件；胶片条与面板若抢走画布，测量感会被稀释。
