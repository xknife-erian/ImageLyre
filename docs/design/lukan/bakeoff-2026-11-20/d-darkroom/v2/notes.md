# 暗房 v2

**布局逻辑**：没有栏。窗口只剩一条窗带与一圈边框；身份在左上，读数在左下，工具是底部一行按键，动作在右上。测量不进表格：六个数挂在一根线上，从 ROI 顶点牵进右下角的暗处，参数缩进签底，就地改、当场变。

**去掉了什么**：菜单栏、工具条、Results 面板、状态栏、所有浮层。没有面板，只有一张挂在样本上的签。

**为什么只属于我**：光决定控件的位置。亮处只许有样本，文字全退到暗部；选中不靠发光边框，而是把 ROI 外的光压暗一格。控件剩下的不是按钮，是名字。

**ImageJ 老用户**：Results、Area/Mean/StdDev/Min/Max/Perimeter、多边形手柄、0.5 µm/px 都在；V/R/P/H/Z 照搬，⌘K 命令替代菜单。

**最大风险**：控件拆到四角又都藏在暗处，第一次打开可能找不到导出；静态图里挂签与样本的因果，也可能读不出来。
