# 标本档案 A4

**结构**：画布最大，右侧一列「标本档案」：身份（SL-2026-0412、B-17、DAPI+GFAP、采集、复核、文件/位深/校准）→ 六项测量 → 单位就地改 → 折叠的溯源（校准链、哈希、插件、trace）。底部是 B-17 批次条，12 张里 4 张可见，可收起。工具退到左缘 5 键，命令退到 Ctrl+K 与一行 echo。

**从 E3 拿了什么**：标本号、批次、染色、采集、复核，外加复核章、缩略图、同批索引；把「一次测量是一份可归档记录」放在第一屏。

**丢了自己什么**：A3 的常驻台账折进 provenance，事件流与命令栏不再常驻；牺牲随时可观测，换档案卡秩序。哈希、沙箱与 trace 仍在，但要展开。

**ImageJ 老用户**：Results 六行仍在第一屏；ROI 03、P 多边形、Analyze › Measure 写在溯源里；Ctrl+Z 与 export CSV 在卡底；Ctrl+K 可输入旧菜单名。

**最大风险**：折叠溯源会让「数字有来路」退到第二眼；右栏下段留白；批次条与档案卡会被读成图片管理器。
