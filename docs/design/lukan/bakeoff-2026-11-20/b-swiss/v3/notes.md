# 取景器

**这条道怎么落地**：整窗就是画布，暗场图满到窗框。四边刻度尺：上边标 µm，左右下只留刻线。四角收口——左上文件、位深、校准与参数；右上主题、撤销、导出、窗钮；左下坐标、像素、缩放；右下六项 Results。ROI 外虚焦压暗、内实焦提亮，白角标框住边界，红线与 P3 顶点标当前选区。参数用 ‹ › 现改现算，无弹窗。

**Lyre 自己的东西**：取景器里没有光圈快门，只有 µm、像素、校准、面积与周长；红线只属于当前 ROI，白刻度只量样本。相机对焦框在这里量的是 1240.5 µm²。

**ImageJ 老用户怎么找路**：菜单、Analyze、Results 与六项指标原名都在；ROI 仍是多边形加可拖顶点，只是从对话框搬到画面边缘。

**最大风险**：暗场取景器容易被先读成相机或修图软件；边缘微字在低亮度屏上偏小，六项读数也可能被当成 HUD 装饰。
