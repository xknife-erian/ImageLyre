# ImageLyre 常用控件规格

| 版本 | 日期 | 状态 | 作者 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 1.0 | 2026-11-20 | 历史 | 林一 | 首版：逐个控件补五态；含开关与整行焦点框 |
| 1.1 | 2026-11-20 | 现行 | 林一 | 按 `state-model.md` 0.1 重做：删开关、焦点统一为底边下划线、表格改「一轨一线」 |

## 0 读法

- **语法在别处。** 状态不是控件的装饰，是同一套语法的投影；语法、叠加与优先级只认 `state-model.md` 0.1，本文只决定「每个控件用哪种形状」，不另立规则。
- **五态五通道。** 当前 = 沿形 2px；选中 = 轴上 2px 轨 + 一档中性底；焦点 = 元素底边 1px 线；悬停 = 只换底；编辑 = 光标 + 底边 1px 线；禁用 = 去掉以上全部。一态一通道，换控件不换语法。
- **三个来源不变。** 尺寸与间距只引 `spacing.md`；字号字重行高只引排印 2.0 的四档；颜色只引 `color-tokens.md` 1.2 的语义名。本文不新增字号、间距阶、色值与状态数。
- **同一元素最多两条线**：一条轨（选中）+ 一条下划线（焦点）；编辑时下划线来自编辑通道，不再叠焦点线。
- **不做三件**：不做整行外框、不做色字、不做填充块（悬停的一档洗底除外）。

## 2 状态落地

| 状态 | 唯一通道 | 控件上的形状 | Token |
| :--- | :--- | :--- | :--- |
| 当前 current | 沿形 2px | 当前 ROI 的描边；不参与控件规则 | `signal.active` |
| 选中 selected | 轴上 2px 轨 + 一档中性底 | 横向控件贴下沿，纵向列表贴左沿 | `signal.active` + `state.selected.bg` |
| 焦点 focus | 元素底边 1px 线 | 按钮、工具格、分段项、复选框行、下拉、菜单项、输入框、表格当前行 | `line.focus` |
| 悬停 hover | 只换底 | 行、按钮、工具格、菜单项、下拉项 | `surface.hover` |
| 编辑 editing | 光标 + 元素底边 1px 线 | 输入框、表格单元格；光标用 `text.t1` | `text.t1` + `line.focus` |
| 禁用 disabled | 去掉以上全部 | 线降 `line.divider`、字降 `text.disabled`，仍可读 | `line.divider` + `text.disabled` |

- 叠加优先级：编辑 > 焦点 > 选中 > 悬停；优先级高的画了，低的就不再重复画同一条线。
- 选中 + 焦点：轨与下划线位置不同，可以并存；同一元素最多两条线。
- 悬停只在没有选中、没有焦点时出现；禁用项没有任何线。
- `signal` 只做 2px 轨与勾：不做文字色、不做填充、不做整块底。

## 3 按钮

三档：主、次、静默。三档同高同字，差别只在**线**与**字色**：主 = 实线 + T1，次 = 细线 + T2，静默 = 无线 + T2。主按钮也不用 `signal`，也不反白。

**规格**

| 项 | 主 | 次 | 静默 |
| :--- | :--- | :--- | :--- |
| 高 | 28 | 28 | 28 |
| 左右内边 | 12 | 12 | 8 |
| 字档 | 13 / 20；拉丁 600、中文 400 | 13 / 20；中文 400 | 13 / 20；中文 400 |
| 底 | `surface.panel` | 透明（露出所在底） | 透明 |
| 线 | 1px `line.border` | 1px `line.divider` | 无（保留 1px 透明占位） |
| 字色 | `text.t1` | `text.t2` | `text.t2` |
| 图标 | 16，与字 gap 8 | 同左 | 同左 |
| 数量 | 一屏一处，只给本屏主动作 | 常规动作 | 低频与面板内联动作 |

**五态**

| 态 | 底 | 线 | 字 |
| :--- | :--- | :--- | :--- |
| 默认 | 见上表 | 见上表 | 见上表 |
| 悬停 | `surface.hover` | 不变（仍是本档的线） | 不变（仍是本档的字色） |
| 按下 | `state.selected.bg` | 不变 | 不变 |
| 焦点 | 不变 | **底边 1px `line.focus`**（替换底边线，不画外框） | 不变 |
| 禁用 | `state.disabled.bg` | `line.divider` | `text.disabled` |

- 三档的分层只发生在默认态；悬停、按下、焦点都不改线与字色，否则三档会塌成一档。
- 焦点只动底边这一条线：左右与上边保持原样，不加环、不加偏移。

**键盘**：Tab 进入，Enter 或 Space 触发；同一组按钮内 ←/→ 或 ↑/↓ 移动焦点；Esc 取消正在进行且可取消的动作；快捷键写在按钮右侧，用 11 mono，如 `Ctrl M`。

**do / don't**

- do：一个动作一个动词，中文 400、拉丁 600；宽度随字长，最短 72。
- do：主按钮靠「实线 + T1 + 拉丁 600」立起来，不靠颜色、不靠加粗中文。
- do：三档同屏时按「一主、一次、其余静默」排，不出现两个主按钮。
- don't：不用 `signal` 铺底、不做反白、不做圆角、不加投影。
- don't：焦点不画外框、不画光环——只是一条底边线。
- don't：按钮里不换行、不截断、不放两个动词（「保存并导出」拆两个）。

## 4 图标按钮与工具格

同一枚 36 方控件，两种用法：纯图标按钮（面板头、窗口控件），工具格（左轨，带键位）。

**规格**

| 项 | 值 |
| :--- | :--- |
| 外框 | 36 × 36 |
| 图标 | 16 × 16 居中，描边 1.25 |
| 键位 | 11 mono，右下角，距右 4、距下 2 |
| 内边 | 0（图标居中，不用 padding 推） |
| 工具间距 | 4（`space.toolGap`） |

**五态**

| 态 | 底 | 图标 | 线 |
| :--- | :--- | :--- | :--- |
| 默认 | 透明 | `text.t2` | 无 |
| 悬停 | `surface.hover` | `text.t1` | 无 |
| 选中 | `state.selected.bg` | `text.t1` | 下沿 2px `signal.active` |
| 焦点 | 不变 | 不变 | 底边 1px `line.focus` |
| 禁用 | 透明 | `text.disabled` | 无 |

**键盘**：Tab 进组，方向键在组内移动（roving tabindex），Space 或 Enter 激活；单键快捷键（V / R / P / H / Z）直接切工具，不抢输入框焦点。

**do / don't**

- do：图标永远配 tooltip（11 字），tooltip 里重复键位。
- do：键位用 11 mono，不用大写字母加粗。
- don't：不做 40、44 的工具格；不做圆角方块；选中不用深色实底反白。
- don't：焦点不画外框；选中轨与焦点线不在同一格同时出现。

## 5 文本、数值、搜索

**规格**

| 项 | 文本框 | 数值框（带单位） | 搜索 / 命令 |
| :--- | :--- | :--- | :--- |
| 高 | 28 | 28 | 28 |
| 内边 | 左右 8、上下 0 | 左右 8、上下 0 | 左右 8 |
| 字档 | 13 / 20 | 13 / 20，等宽 | 13 / 20 |
| 底 / 线 | `surface.input` / `line.border` | 同左 | 同左 |
| 结构 | 纯值 | 值（右对齐）+ 1px 分隔 + 单位 11 `text.t2` | 16 图标 + 值 + 右侧 `Ctrl K` 11 `text.t3` |
| 单位 | — | 可点，就地换单位，不开对话框 | — |
| 数值对齐 | — | 等宽、右对齐、固定小数位，不截断 | — |

**六态**（编辑是输入框独有的状态）

| 态 | 底 | 线 | 字 / 光标 |
| :--- | :--- | :--- | :--- |
| 默认 | `surface.input` | `line.border` | `text.t1`；占位 `text.t3` |
| 悬停 | `surface.hover` | `line.border` | 不变 |
| 选中（文本选区） | 不变 | 不变 | 选区底 `state.selected.bg`，字不反白 |
| 焦点 | 不变 | **底边 1px `line.focus`** | 不变 |
| 编辑 | 不变 | 底边 1px `line.focus` | 光标 1px `text.t1` 在插入点 |
| 禁用 | `state.disabled.bg` | `line.divider` | `text.disabled`，无光标 |

- 焦点与编辑都是底边一条线；区别只在有没有光标。编辑时不再另画焦点线，避免两条线叠在同一位置。
- 不画输入框外框；聚焦时也不加投影、不加光环。

**键盘**：Tab 进入；Enter 提交并退出；Esc 还原为进入前的值；数值框 ↑/↓ ±1、Shift+↑/↓ ±10、PageUp/PageDown ±10；进入数值框全选，方便直接覆盖；单位后缀用 Alt+↓ 展开就地菜单，↑/↓ 换单位、Enter 确认、Esc 取消；搜索框 `Ctrl K` 聚焦，Esc 清空并退出。

**do / don't**

- do：数字与单位之间一个不换行空格；单位不进数字列，单独 11 档。
- do：校验失败时就地给底边 1px `line.focus` + 11 字说明，不弹窗。
- don't：不用 placeholder 当标签；标签在字段左侧或上方。
- don't：不把单位做成第二个输入框；不截断小数。
- don't：不给输入框加外框或阴影来表示焦点。

## 6 分段控件

横向单选，一屏内的视图切换。测量单位只有两格：**µm² / px²**；同型控件还用于关/开、1 位/2 位、浅/深。

**规格**：外高 28；项左右 12；字 13 / 20；外框 1px `line.border`；项间 1px `line.divider`；底 `surface.panel`。

**五态**

| 态 | 底 | 线 | 字 | 标 |
| :--- | :--- | :--- | :--- | :--- |
| 默认（未选） | `surface.panel` | `line.divider` | `text.t2` | 无 |
| 悬停（项） | `surface.hover` | 不变 | `text.t1` | 无 |
| 选中 | `state.selected.bg` | 不变 | `text.t1` | 下沿 2px `signal.active` |
| 焦点 | 不变 | **焦点项底边 1px `line.focus`**（不是整组外框） | 不变 | 选中项保留 2px 轨 |
| 禁用 | `state.disabled.bg` | `line.divider` | `text.disabled` | 去掉选中标与焦点线 |

- 焦点落在**项**上，不落在组上：Tab 进组停在当前项，焦点线只在该项底边；选中轨可能在另一项，两条线位置不同。
- 选中项与焦点项可以是同一项：此时底边同时有 2px 轨与 1px 焦点线，轨在内、线在下，不合并、不加粗。

**键盘**：Tab 进组停在当前项；←/→ 立即切换选中（单选组行为）；Home/End 到首尾；Space 选中当前焦点项。

**do / don't**

- do：两格为主，最多三格；等宽或按字长，不拉伸到整行。
- do：选中靠「底 + 下沿 2px」，不靠加粗、不靠反白。
- don't：不做三格以上的单位切换（µm² / px² 只有两格）。
- don't：不给整组套焦点框；焦点只画在焦点项底边。
- don't：不把分段做成胶囊、不做圆角底。

## 7 二元选择

二元参数只有三种形式，没有第四种；**不出现轨道与旋钮，不出现滑块开关**。

| 场景 | 形式 | 例子 |
| :--- | :--- | :--- |
| 设置、表单 | 复选框：16 方框 + 2px 勾 + 选中底 | 显示全部、包含边缘 |
| 菜单 | 勾选菜单项：行首 2px 勾 | 显示标尺、吸附到像素 |
| 行内参数 | 两段式分段：关 / 开，或 µm² / px² | 自动重算、单位 |

**复选框五态**

| 态 | 框 | 勾 | 底 / 线 | 字 |
| :--- | :--- | :--- | :--- | :--- |
| 默认 | 16 × 16，`surface.input` + `line.border` | 无 | 行透明 | `text.t1` |
| 悬停 | 同上 | 无 | 行底 `surface.hover` | `text.t1` |
| 选中 | 16 × 16，底 `state.selected.bg` | 2px `signal.active` | 行透明 | `text.t1` |
| 焦点 | 同上 | 同上 | 行底边 1px `line.focus` | `text.t1` |
| 禁用 | `line.divider` | 无 | 行透明 | `text.disabled` |

- 选中 = 方框 + 选中底 + 2px 勾，三者同时出现；焦点只加行底边一条线，不加方框外框。
- 勾画在 16 方框内，长 10、线宽 2，随缩放只换物理像素，不换 DIP。
- 禁用不画勾；框与字降级，标签仍完整可读。

**勾选菜单项**

| 态 | 底 | 勾 | 线 |
| :--- | :--- | :--- | :--- |
| 未勾 | `surface.panel` | 无 | 无 |
| 悬停 | `surface.hover` | 无 | 无 |
| 已勾选 | `state.selected.bg` | 行首 2px `signal.active` 勾 | 无 |
| 焦点 | 不变 | 保留勾 | 项底边 1px `line.focus` |
| 禁用 | `state.disabled.bg` | 勾降为 `text.disabled` | 无 |

- 勾选标记是「值」，画成 2px 勾，不是轨；菜单里「当前项」才用左沿 2px 轨。
- 勾与快捷键同高：勾在左，标签居中，快捷键右对齐。

**两段式分段**

- 与 §6 同一个控件：两项、字 13、选中下沿 2px、焦点项底边 1px。
- 文案用「关 / 开」「µm² / px²」「1 位 / 2 位」，两字以内，不加图标。

**do / don't**

- do：设置与表单用复选框；菜单用勾；行内参数用两段式分段。
- do：勾永远是 2px 线，不用对勾字符（✓），不用 1px 勾，不染 `text.t1`。
- don't：不做开关、不做轨道 + 旋钮、不做滑块开关；二元选择不需要它。
- don't：不让复选框与分段长得像：一个是方框，一个是文字格。

## 8 表头与表行

**规格**：表头高 24，11 / 16，拉丁 600，`text.t3`，左右内边 8；表行高 28，13 / 20，数值用等宽右对齐，左右内边 8；列间只用 1px `line.divider` 横线，不画竖线。

**七态**

| 态 | 底 | 线 | 字 | 标 |
| :--- | :--- | :--- | :--- | :--- |
| 默认行 | `surface.panel` | 下 1px `line.divider` | `text.t1` | 无 |
| 悬停行 | `surface.hover` | 不变 | `text.t1` | 无 |
| 选中行 | `state.selected.bg` | 不变 | `text.t1`（不升、不染） | 左沿 2px `signal.active` |
| 焦点行 | 不变 | **当前行底边 1px `line.focus`**（从行首贯到行尾） | 不变 | 无 |
| 编辑 | `state.selected.bg` | 该单元格底边 1px `line.focus` + 光标 | 不变 | 行左沿 2px 轨保留 |
| 选中 + 焦点 | `state.selected.bg` | 左沿 2px + 行底 1px `line.focus` | 不变 | 两条线并存，位置不同 |
| 禁用行 | `state.disabled.bg` | `line.divider` | `text.disabled` | 去掉标 |

- 选中只做两件事：一档中性底 + 左沿 2px；不改字色、不加整行边框、不加粗。
- 焦点是**行底边一条线**，从行首贯到行尾；不画单元格框、不画整行外框。
- 编辑是**单元格**的事：光标在该格、底边线也只在该格；行仍保留选中轨。
- 选中 + 焦点同时存在时，左沿贴行首、下划线贴行底，互不覆盖。

**键盘**：↑/↓ 移动当前行；Home/End 到首尾；Space 选中/取消；Shift+↑/↓ 扩选；Enter 进入编辑；Esc 退出编辑；PageUp/PageDown 翻页；表头获得焦点时 Enter 排序。

**do / don't**

- do：数值列右对齐、等宽、固定小数位；单位放表头，不进单元格。
- do：选中行只加左沿 2px，不整行反白、不加粗、不改字色。
- do：焦点画在行底边，编辑画在单元格底边；两条线永远不同高。
- don't：不把选中行的文字染成信号色——`signal` 不做文字色，数字永远是 T1。
- don't：不给整行套外框、不给单元格套框；焦点只有下划线。
- don't：不用斑马纹；行与行靠 1px 线。
- don't：不在行里放两个可点区域；行的点击目标是一整行。

## 9 状态项

只读，不可聚焦、不可点击。

**规格**：字 11 / 16；标签 `text.t3`，值 等宽 `text.t2`（当前值可用 `text.t1`）；项间 24（`space.statusGap`）；左右 16（`space.statusPadX`）；高 28（`size.statusbar.height`）。

**do / don't**

- do：状态项只放「读数」——坐标、像素值、缩放、校准、位深。
- don't：不把按钮塞进状态栏；不放需要点击才能读的信息。

## 10 提示、滚动条、滑块、步进

**工具提示**：11 / 16，`text.t1`；底 `surface.panel`；1px `line.border`；内边 4 / 8；最大宽 320，超出折行；无投影；悬停 400ms 后出现，焦点触发同效，Esc 关闭；不得承载唯一信息。

**滚动条**：轨道宽 8（`space.2`），底透明；滑块宽 8，`line.border`，最短 24；悬停 `text.t3`，拖动中 `text.t2`；无箭头按钮；区域聚焦时 PageUp/PageDown 翻页。

**滑块**：轨道高 4（`space.1`），`line.divider`；已选段 4，`line.border`（中性，不用 signal）；手柄 16（`space.4`）方形，`surface.panel` 底 + 1px `line.border`；悬停时手柄描边 `text.t3`；拖动中手柄描边 `text.t2`、底 `state.selected.bg`；焦点时滑块底边 1px `line.focus`；禁用时轨道 `state.disabled.bg`、手柄 `line.divider`。键盘 ←/→ ±1，Shift ±10，Home/End 到两端。

**步进**：每个按钮 24 宽 × 28 高；`surface.panel` + `line.border`；− 与 + 各一枚，紧贴数值框右侧，中间 1px `line.divider`；悬停 `surface.hover`，按下 `state.selected.bg`，焦点按钮底边 1px `line.focus`，禁用 `text.disabled`；↑/↓ 与按钮同步，按住 400ms 后连续步进。

**do / don't**

- do：提示、滚动条、滑块、步进都只用中性色与 1px 线。
- don't：滚动条不做悬停变宽、滑块不用 signal 填充、步进不做圆角胶囊。
- don't：滑块与步进的焦点也不画外框或光环，只画底边线。

## 12 验收

1. **尺寸**：所有控件的高、宽、内边、间距都能在 §1 或 `spacing.md` §5 找到名字，没有裸数值。
2. **颜色**：所有底、线、字、标都能在 `color-tokens.md` 1.2 找到语义名；没有第二强调色。
3. **五态**：§3–§10 的六种状态都能在样张里找到；禁用项去掉了全部线与标。
4. **不反白**：任何控件的任何态都没有深色实底配浅色字；`signal` 不做文字色。
5. **键盘走一遍**：从选工具到导出，焦点始终是一条底边 1px 线；**任何位置都不出现外框，也不出现整行框**。
6. **叠加**：选中 + 焦点最多两条线（轨 + 下划线），位置不同；编辑时只有一条底边线加光标。
7. **二元选择**：全局搜索无「开关」「轨道」「旋钮」「滑块开关」；二元参数只用复选框、勾选菜单项、两段式分段。
8. **表格**：选中只有左沿 2px + 底；焦点是行底边一条线；编辑是单元格光标 + 格底边线；没有单元格框。
9. **并排**：亮暗两版控件尺寸逐项一致，只有颜色不同。
