# ImageLyre 颜色与状态基线

| 版本 | 日期 | 状态 | 作者 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 1.0 | 2026-11-20 | 定稿 | 林一 | 明暗两套表面、线、文字三层、信号与四组状态；每个色值有语义名与对比度；无渐变、投影、玻璃拟态与第二强调色 |

## 0 三条前提

1. **同构换值。** 明暗两套 token 一一对应：数量相同、语义相同、位置相同，只换色值；没有「暗色少一层灰」。
2. **颜色只做层级辅助。** 灰度截图后主次仍成立；颜色不承担唯一信息，也不代替字号、字重与留白。
3. **一屏只有一处「当前」。** `signal` 只标当前 ROI 与运行中，其余一律中性；没有第二个强调色。

## 1 命名

| 前缀 | 管什么 | 例 |
| :--- | :--- | :--- |
| `surface.*` | 底 | `surface.panel` |
| `line.*` | 1px 线 | `line.border` |
| `text.*` | 文字层 | `text.t2` |
| `signal.*` | 当前与运行 | `signal.active` |
| `state.*` | 交互状态 | `state.selected.bg` |
| `canvas.*` | 图像叠加，不随主题 | `canvas.ink` |

- 名字说用途，不说深浅：没有 `gray-200`、`tint-2`、`primary-500`。
- 一个 token 只干一件事；同一个值有两种语义时给两个名字（见 `signal.running`）。
- 界面里不出现本表之外的色值，也不用十六进制直接写进控件。

## 2 表面 surface

| Token | 亮 | 暗 | 用途 | T1 在亮底 | T1 在暗底 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `surface.window` | `#F4F1E8` | `#151512` | 窗口底：标题栏、菜单、状态栏、工具轨 | 15.30:1 | 15.20:1 |
| `surface.panel` | `#FBFAF4` | `#1C1C18` | 面板、列表、浮层 | 16.53:1 | 14.20:1 |
| `surface.canvas` | `#E7E2D3` | `#0E0E0C` | 画布底：图像四周的台面 | 13.35:1 | 16.05:1 |
| `surface.input` | `#FFFDF8` | `#12120F` | 输入框、下拉、数值格的底 | 17.00:1 | 15.59:1 |
| `surface.hover` | `#EAE5D5` | `#2A2A24` | 悬停底（替换原底，不叠加） | 13.72:1 | 11.99:1 |

- 面板永远比窗口亮一档，亮暗两套都成立；层级靠这一档与 1px 线，不靠投影。
- 画布底两套都最深：图像是唯一被照亮的东西，台面退到它后面。
- 输入底是「凹槽」：亮色取最白、暗色取最黑，边界一律由 `line.border` 给出。
- 悬停底是实色，替换而非叠加；只用于窗口与面板内的行、按钮、工具格，不用于画布。

## 3 线 line

| Token | 亮 | 暗 | 用途 | 对 `surface.panel`（亮 / 暗） |
| :--- | :--- | :--- | :--- | :--- |
| `line.divider` | `#DFD8C6` | `#2A2A23` | 同级分隔：行与行、段与段 | 1.36:1 / 1.18:1 |
| `line.border` | `#BDB6A4` | `#3C3C33` | 控件、面板、输入框的边框 | 1.93:1 / 1.54:1 |
| `line.focus` | `#B83A24` | `#D89A4A` | 键盘焦点环 | 5.47:1 / 7.03:1 |

- 只有 1px：没有 2px 分隔线，没有投影，没有内阴影。
- 分隔线只分隔同级；跨级（面板 vs 窗口）一律用 `line.border` 画外框。
- 焦点环画在控件外 1px 处（1px 偏移），控件尺寸不变；它是线，不是光晕。
- 焦点环取 `signal`：焦点也是「当前」，不为它新增强调色；形状是线，不是光晕。
- 焦点环的对比度按非文本要求 ≥3:1（实测 5.47 / 7.03）。

## 4 文字 text

| Token | 亮 | 暗 | 用途 | 面板（亮 / 暗） | 最弱合法底（亮 / 暗） |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `text.t1` | `#1B1B16` | `#ECEAE3` | 正文、读数、菜单、标题 | 16.53 / 14.20 | 12.73 / 10.88（选中底） |
| `text.t2` | `#4A4840` | `#B8B5AC` | 字段值、状态、单位 | 8.76 / 8.34 | 6.75 / 6.39（选中底） |
| `text.t3` | `#6B675C` | `#8C8A81` | 标签、表头、脚注、哈希 | 5.40 / 4.94 | 4.16 / 3.78（选中底） |
| `text.disabled` | `#827C6E` | `#7E7B70` | 不可用 | 3.97 / 4.03 | 3.55 / 4.16（禁用底） |

- 前三层原样取自排印 2.0 §8，未改；本文只是把它们绑到具体表面上，并补出第四层「禁用」。禁用色不参与层级，只表示不可用。
- 正文与读数 ≥4.5:1（实测最低 6.39）；弱化文字 ≥3:1（最低 3.78）；禁用 ≥3:1（最低 3.55）。
- 不设 T4：更弱的信息靠位置与留白，不靠第四层灰。
- 禁用文字仍要完整可读，不截断、不省略；变灰只是提示，不是信息本身。

## 5 信号 signal

| Token | 亮 | 暗 | 用途 | 面板（亮 / 暗） | 窗口（亮 / 暗） | 画布（亮 / 暗） |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `signal.active` | `#B83A24` | `#D89A4A` | 当前 ROI、当前行、当前文档标签 | 5.47 / 7.03 | 5.07 / 7.53 | 4.42 / 7.95 |
| `signal.running` | `#B83A24` | `#D89A4A` | 运行中、正在测量 | 同上 | 同上 | — |

- 只标当前：当前 ROI 的 2px 边、当前项的 2px 标（列表行贴左边，页签贴顶边）、运行中的 6px 点或图标描边。
- 不做面：不填充整行、不做按钮底色、不做图表面积、不做选中项的大色块。
- 不做正文：需要文字时用 T1；`signal` 只做标记。
- 同一时刻「当前选区」与「运行中」可并存，用形状区分（线 / 点），不增设第二档色。
- 亮色朱红压在图上不足 3:1，画布上的 ROI 必须加 1px `canvas.edge` 外沿（见 §8）。

## 6 状态四组

### 6.1 状态专用底

| Token | 亮 | 暗 | 用途 | 落在其上的文字对比（亮 / 暗） |
| :--- | :--- | :--- | :--- | :--- |
| `state.selected.bg` | `#E3DDCB` | `#31312A` | 选中行、选中项、当前文档标签 | T1 12.73 / 10.88；T3 4.16 / 3.78 |
| `state.disabled.bg` | `#F1EDE0` | `#191915` | 禁用按钮、禁用输入 | 禁用字 3.55 / 4.16 |

### 6.2 四组状态

| 状态 | 亮 | 暗 | 规约 |
| :--- | :--- | :--- | :--- |
| 悬停 hover | 底 `surface.hover`；线、字不变 | 底 `surface.hover`；线、字不变 | 只换底，不换字重 |
| 选中 selected | 底 `state.selected.bg` + 2px `signal.active` 标；字升 `text.t1` | 底 `state.selected.bg` + 2px `signal.active` 标；字升 `text.t1` | 底 + 标，不加外框 |
| 焦点 focus | 线 `line.focus`，1px，外偏 1px | 线 `line.focus`，1px，外偏 1px | 只换线，不换底 |
| 禁用 disabled | 底 `state.disabled.bg`；线 `line.divider`；字 `text.disabled` | 底 `state.disabled.bg`；线 `line.divider`；字 `text.disabled` | 可读，不承载唯一信息 |

- **悬停**：行、按钮、工具格、下拉项共用同一个底；不出现第二种悬停色。禁用项没有悬停态。
- **选中**：底只提供「被按住」的层次，真正指路的是 2px 信号标；标贴在元素与相邻元素相接的那条边上（列表贴左、页签贴上）；多选时每行都有标，信号不因数量增加而增强，也不填充整块。
- **焦点**：只在键盘路径上出现；输入框聚焦时外框换 `line.focus`、底不变；鼠标点击不保留焦点环。焦点与选中可同时存在，二者分别用线与标，互不覆盖。
- **禁用**：底、线、字三层同时降级；鼠标不出现悬停底、不出现指针变化以外的提示。禁用不能是唯一路径——该动作必须在别处有可读说明或替代入口，否则不做禁用，改为点击后说明原因。

## 8 画布叠加

图像本身不随主题切换，所以压在图上的一对颜色两套同值，不参与明暗切换。

| Token | 两套同值 | 用途 | 对比 |
| :--- | :--- | :--- | :--- |
| `canvas.ink` | `#F2EFE6` | 比例尺、坐标与像素值标签 | 对 `canvas.edge` 17.13:1 |
| `canvas.edge` | `#0B0B09` | 叠加件的 1px 外沿 | — |

- 比例尺与标签用 `canvas.ink`；需要压住亮图时加实底块 + 1px `canvas.edge` 轮廓，不用半透明遮罩、不用模糊。
- 画布上的 ROI 用 `signal.active`，外压 1px `canvas.edge`，保证任意图都有边界。
- 不做文字描边：需要时用实底块，不用给字加边。

## 9 禁止清单

- 禁止渐变、投影、内阴影、玻璃拟态、模糊、发光。
- 禁止第二强调色：除 `signal` 外不出现饱和色，图表也用灰阶。
- 禁止 `signal` 当填充、当正文、当装饰。
- 禁止颜色作为唯一信息：状态必须另有形状、位置或文字。
- 禁止表外色值；禁止非 1px 的线；禁止用 T3 写正文；禁止用禁用态承载唯一信息。

## 10 验收

1. **取色**：全屏取样，所有色值都能在本表按名查到，没有表外值。
2. **对比度**：正文 ≥4.5、弱化 ≥3、禁用 ≥3、焦点 ≥3，两套都过（见 §7）。
3. **灰度**：去色后主次、选中、禁用仍可辨。
4. **信号**：一屏只有「当前」一件事被 `signal` 标出——当前 ROI（含它在列表里的那一行）与运行中；没有第二处填充、没有第二处线条。
5. **并排**：明暗两套 token 一一对应，没有哪套多一层灰。
6. **放大**：200% 下所有线仍是 1 DIP，没有阴影与光晕。

## 11 边界

- 字号、字重、行高、字距见 `typography.md` 2.0；间距与控件尺寸见 `spacing.md`；本文只定颜色与状态。
- 图像内容、LUT 与伪彩不在本文；画布叠加只定表中的两个值。
- 21 与 22 的现有色值按本表替换：先换表面与线，再换文字，最后接 `signal`；替换不改变结构、字号与间距。
