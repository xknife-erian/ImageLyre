# C · 游标

**名字** 游标。像一把搁在台面上的卡尺。

**一句话直觉** 手伸过去就能量，读数就在刻度上。

**布局** 左侧 40px 工具轨，五工具各带角标；中央是暗井里的画布；画布下沿钉一条参数条，阈值、单位、采样当场改；Results 六行六列紧贴其下，选中行用一道蓝线钉住；状态栏常驻坐标、像素值、校准与主题。零浮层。

**色彩与材质** 中性灰阶加唯一一种蓝，只给选中、活动、正在运行。边界全是 1px 硬线，圆角 2–3px，没有卡片、投影与第二层光泽。画布是唯一暗下去的地方，样本是唯一发光的东西。

**字体与数字** 系统字体 10–12.5px；数字等宽右对齐，单位缩成灰字，一列能竖着扫。快捷键散在角标、Ctrl K、Ctrl M、Esc/Enter 里，不喊口号。

**动效** 只解释空间：面板从所属边滑出，选中零过渡，数字不跳。

**取舍** 放弃了对话框、向导、浮层、卡片与大按钮，也放弃了第一眼的从容；代价是看着密。

**最容易被误认成什么** VS Code 或 Photoshop 那类专业编辑器；细看才认出是 ImageJ 的房间。也有人会说只是换皮，直到看见改参数当场变、且没有弹窗。
