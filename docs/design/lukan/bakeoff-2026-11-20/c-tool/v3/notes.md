# C3 · 读数台

**这条道怎么落地** 标题、菜单、选项栏、文档标签四条横带，下接居中画布与状态栏；左两列工具，右 300px 停靠。深灰中性，一种蓝只给选中、活动与实时。直方图画阈值带与均值线；ROI 列表用复核框，不做缩略图。

**Lyre 自己的东西** 选项栏属于对象：选中 ROI 4，整条栏就是它的测量参数（阈值、单位、小数位、实时），换选就整体换一次。右停靠把读数、直方图、参数排成一台仪器，共用 ROI 4 与实时灯；状态栏常驻像素值、校准与位深。

**ImageJ 老用户怎么找路** Analyze 与 Process 都在，Ctrl M 仍是 Measure，右上是 Results 的继任者「测量」面板，ROI Manager 变成 ROI 列表，Set Scale 变成「校准」面板。

**最大风险** 太像 Photoshop：可能被当成修图台，测量被读成信息面板。压住它的只有三处：选项栏的测量组、直方图的阈值带、状态栏的校准。
