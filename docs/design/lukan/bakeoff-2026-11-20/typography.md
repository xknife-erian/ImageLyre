## 0 三条前提

1. **两版同字，只换色。** 21 与 22 的字号、字重、行高、字距逐项相同；明暗只改颜色与材质，不改排印。
2. **八档以内。** 工作窗口只用 10–24px 的八档；不出现第九档，不靠缩小字号解决密度。
3. **层级靠排印。** 大小、字重、行高、位置、留白决定层级；颜色只做辅助。灰度打印后层级仍须成立。

### 0.1 载体说明

本文的数值是**设计值**，单位按 DIP（设备无关像素）计（100% 时 1 DIP = 1 px），不是 CSS 像素；HTML 字样页只是视觉参照，不是实现。Avalonia 落地时由平台字体与主题资源承载，映射见 `typography-avalonia.md`；本文只定设计口径。

- 字号、行高、字距以 DIP 设计值表述；HTML 字样页里的 CSS 变量只作视觉复现，不是实现契约；
- 字体回退的意图由 `font-family` 栈表达，Avalonia 侧以平台字体管理配置落地；
- 数字等宽与小数对齐由天生等宽字体保证；HTML 字样页用 `font-feature-settings` 只作模拟；
- Avalonia 主题切换用亮/暗主题资源；HTML 字样页用类名只作对照。

## 1 字体家族

只用系统字体，不下载、不内嵌 Web Font。

```css
--font-ui:
  "Segoe UI Variable Text", "Segoe UI", system-ui, -apple-system,
  BlinkMacSystemFont, "Helvetica Neue", Arial,
  "Microsoft YaHei UI", "PingFang SC",
  "Noto Sans CJK SC", "Source Han Sans SC", sans-serif;

--font-mono:
  "Cascadia Mono", "Cascadia Code", Consolas, "SF Mono", Menlo,
  "Roboto Mono", "DejaVu Sans Mono", "Liberation Mono",
  ui-monospace, monospace;
```

| 用途 | 字体 | 说明 |
| :--- | :--- | :--- |
| 界面无衬线 | `--font-ui` | Windows 首选 Segoe UI；macOS 落到 system-ui/SF；Linux 落到 Noto/Cantarell |
| 中文回退 | Microsoft YaHei UI → PingFang SC → Noto Sans CJK SC → Source Han Sans SC | 放在拉丁字体之后；拉丁先用界面字，汉字才落到中文字体 |
| 数字等宽 | `--font-mono` | Windows 首选 Cascadia Mono，其次 Consolas；macOS 用 SF Mono/Menlo；Linux 用 DejaVu/Liberation |
| 中文等宽 | 不使用 | 等宽列只放数字、拉丁 ID、单位、文件名；含中文的值改用 `--font-ui` |

规则：中文不使用衬线字体，不与拉丁字体混排成两种气质；`font-synthesis: none`，禁止系统合成粗体与斜体。

## 2 字号阶

八档，全部落在 10–24px。行高为 4px 基线的整数倍。

| 档 | 字号 / 行高 | 默认字重 | 用途 | 出现位置 |
| :--- | :--- | :--- | :--- | :--- |
| 24 | 24 / 32 | mono 400 | 身份主键：样本号 | 21/22 右栏身份段第一行；一屏一个 |
| 20 | 20 / 28 | mono 400 | 读数 L：当前 ROI 的主读数 | ROI 旁标签、选中测量的强调值 |
| 18 | 18 / 24 | sans 600（拉丁） | 窗口标题 | 标题栏应用名；文件名同级 400 |
| 16 | 16 / 24 | 拉丁 600 / 中文 400 | 面板标题 | 「标本档案 / Specimen Record」 |
| 14 | 14 / 20 | mono 400 | 读数 M：六项 Results | 测量表所有数值；命令面板标题用 sans 600（拉丁）同档 |
| 12 | 12 / 20 | sans 400 | 正文、菜单、字段值、按钮、面板列表项 | 全局默认正文 |
| 11 | 11 / 16 | sans 400 / 600 | 字段标签、段标题、表头、状态栏、工具提示 | 400 用于标签；600 只给拉丁大写段标题/表头 |
| 10 | 10 / 16 | sans 400 / mono 400 | 单位、快捷键、哈希、拉丁脚注 | 全局下限；中文脚注升到 11，不再向下 |

- 读数分三级：**L 20 / M 14 / S 11**。L 只给一个主读数；M 给六项 Results，统一字号，不因重点单独放大；S 给坐标、缩放、像素值等伴随读数。
- 24 每屏最多一个，用于身份主键；不用于按钮、标签或强调。
- 字号不随面板宽度缩小；空间不足时先折叠次要字段、换行或加宽面板。

## 3 字重

| 字重 | 允许 | 用途 | 限制 |
| :--- | :--- | :--- | :--- |
| 400 Regular | 是 | 正文、字段值、表值、单位、菜单、工具提示、读数 | 默认 |
| 500 Medium | 是 | 拉丁面板标题、按钮、选中项、命令面板标题 | 只用于拉丁；中文请求 500 实际落 400 |
| 600 Semibold | 是 | 窗口标题、拉丁大写段标题、拉丁表头、当前状态 | 只用于拉丁；中文请求 600 实际落 700，禁用 |
| 700 Bold | **禁止** | — | 任何位置不得出现 |
| 斜体 / 描边 | **禁止** | — | 不用 `font-style: italic`、`oblique`、`-webkit-text-stroke` |

- **中文只有 400**：YaHei / PingFang 没有 Medium 与 Semibold 面，实测 500 落到 400、600 落到 700；中文的层级只能靠字号、T1/T2/T3 与留白，不能靠字重。
- **拉丁的 500 与 600 在 Windows 上是同一笔画**：Segoe UI 与 Segoe UI Variable Text 都把两者落到 Semibold；不要把 500 与 600 当作两级字重使用，同屏只选其中一级，层级靠字号与颜色。
- 等宽数字只用 400：Consolas 等字体没有 500，请求 500 只会合成；读数强调靠 20px 与 T1，不靠加粗。
- `font-synthesis: none` 必须开启；系统缺字重时允许回退，不允许合成。

## 4 行高与字距

| 类别 | 字号 / 行高 | 字距 | 说明 |
| :--- | :--- | :--- | :--- |
| 显示与身份 | 24 / 32 | -0.01em | 一处一个 |
| 读数 L | 20 / 28 | 0 | 等宽数字不拉字距 |
| 窗口标题 | 18 / 24 | -0.01em | 应用名 600，文件名 400 |
| 面板标题 | 16 / 24 | 0 | 中文 400 |
| 读数 M | 14 / 20 | 0 | 表格行高 28（20 + 8 间距） |
| 正文 | 12 / 20 | 0 | 中文行高不低于 1.6 |
| 标签 / 状态 | 11 / 16 | 0（拉丁大写 0.10em） | 中文不加字距 |
| 单位 / 脚注 | 10 / 16 | 0 | 最小档 |
| 菜单 | 12 / 20 | 0.01em | 仅拉丁 |
| 数字行 | 14 / 20、20 / 28、11 / 16 | 0 | 等宽，小数对齐 |

- **大写拉丁标签**（`IDENTITY`、`RESULTS`）字距 0.10em；中文并列部分字距 0，不用 `text-transform` 作用于中文。
- 表头用正常大小写（`Area`、`Mean`），字距 0；不把 ImageJ 的列名改成全大写。
- 中文行不使用 `letter-spacing`，不 `text-align: justify`；拉开中文字距视为错误。
- 字距在 Avalonia 里是绝对 DIP，不是 em：24px 的 −0.01em 记 −0.24，18px 记 −0.18，11px 大写 0.10em 记 +1.10，12px 菜单 0.01em 记 +0.12；实现按 DIP 写，不按 em 写。

## 5 数字规则

### 5.1 字体与对齐

- 所有测量值、坐标、像素值、缩放、校准、时间、哈希、版本号用 `--font-mono` 400。
- 数字列一律**右对齐**；Avalonia 由天生等宽字体保证，HTML 字样页用 `font-variant-numeric` 与 `font-feature-settings` 模拟。
- **小数对齐**：同一列固定小数位，右对齐即小数点对齐；不同小数位的量不放进同一列。
  - Area 1 位、Mean 1 位、StdDev 1 位、Min 0 位、Max 0 位、Perimeter 1 位。
  - 保留末尾 0（`1433.0`），不因显示去掉精度。
- 单位不进入数字列：数字右对齐到列边，单位另起一个 10–11px 的左对齐位，不参与右对齐。

### 5.2 千分位与符号

| 场景 | 规则 |
| :--- | :--- |
| 读数列 | **不加千分位**；整数位再长也保持连续数字，右对齐靠等宽 |
| 正文 / 摘要 | 需要分隔时用不换行空格 U+00A0（`12 480.5`）；不用 U+202F，等宽族里它只占半格，会把列拉歪 |
| 坐标 / 像素 / ROI 编号 | 不加千分位（`512`、`384`、`01`） |
| 负数 | 界面用减号 U+2212（`−21.7`）；CSV 用 ASCII 连字符 |
| 百分数 | 不加空格（`200%`） |
| 数字与 SI 单位 | 一个不换行空格 U+00A0（`1240.5 µm²`、`0.5 µm/px`） |
| 微米 / 平方微米 | 用 U+00B5 的 `µ` 与 U+00B2 的 `²`；不写 `um2` |
| 数字与中文量词 | 一个普通空格（`6 个 ROI`、`3 张切片`） |

### 5.3 单位降级

单位按“读数降一级”处理，不另造字号：

| 读数 | 数值字号 / 色层 | 单位字号 / 色层 |
| :--- | :--- | :--- |
| L | 20 / T1 | 14 / T2 |
| M | 14 / T1 | 11 / T2 |
| S | 11 / T1 | 10 / T3 |
| 表头单位 | — | 10 / T3 |

单位用 `--font-ui` 400，不用等宽；单位永远贴在数值后同一行，不换行、不省略、不截断。

### 5.4 CSV 与界面

- **精度一致**：界面与 CSV 共用同一套小数位规则；界面加单位，CSV 只写原始数值；千分位不进数字列。
- CSV 数值列：点号小数、无千分位、无单位、无空格；单位放表头或 sidecar 元数据。
- CSV 的负号为 ASCII `-`，界面为 U+2212；两者数值相同。
- CSV 表头用 ImageJ 原名：`Area,Mean,StdDev,Min,Max,Perimeter`；界面列名同源。
- 界面不得为了好看改变精度；CSV 不得为了机器可读改变小数位。两者对不上即缺陷。

## 6 中英混排

| 边界 | 规则 | 示例 |
| :--- | :--- | :--- |
| 中文 ↔ 拉丁词 | 一个普通空格 | `测量 Results`、`当前 ROI` |
| 数字 ↔ 中文量词 | 一个普通空格 | `6 个 ROI`、`3 张切片` |
| 数字 ↔ SI 单位 | 一个不换行空格 | `1240.5 µm²`、`0.5 µm/px` |
| 拉丁 ↔ 数字 | 一个普通空格 | `ROI 01`、`Ctrl K` |
| 双语标签斜杠 | 两侧各一个空格 | `身份 / IDENTITY` |
| 中文标点前 | 不加空格 | `测量，导出。` |
| 百分号 / 角度 | 不加空格 | `200%`、`45°` |

- 中文不加大写字距；需要大写与字距时，只包住拉丁片段（HTML 示例：`<span class="en">IDENTITY</span>`）。
- 中文字体只从回退链取；不用全角拉丁/数字；不用全角空格凑间距。
- 中文和英文并排时，行高按中文给（12/20、11/16），避免英文贴顶。
- 双语段标题统一写法：中文 400 + 空格 + `/` + 空格 + 拉丁大写 600（0.10em）。例：`身份 / IDENTITY`。

## 8 明暗两套的对比度底线

21 亮：纸 `#F4F1E8`；22 暗：底 `#151512`。两套用同一组角色，只换颜色。

| 色层 | 21 亮 | 对比度 | 22 暗 | 对比度 | 用途 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| T1 主文 | `#1B1B16` | 15.3:1 | `#ECEAE3` | 15.2:1 | 正文、读数、标题 |
| T2 次文 | `#4A4840` | 8.1:1 | `#B8B5AC` | 8.9:1 | 字段值、状态、次标题 |
| T3 弱化 | `#6B675C` | 5.0:1 | `#8C8A81` | 5.3:1 | 标签、单位、脚注 |
| Signal | `#B83A24` | 5.1:1 | `#D89A4A` | 7.5:1 | 当前 ROI、当前状态；不做正文 |
| 细线 | `#CFCABA` | 非文字 | `#3A3832` | 非文字 | 1px 分隔线 |

- **正文 ≥ 4.5:1；弱化文字 ≥ 3:1；两者都不低于 10px。** 本基线的 T3 已到 5:1，不靠 3:1 的边缘值。
- 3:1 只允许用于禁用态与非文字线；禁用文字不得承载唯一信息。
- Signal 只标当前，不做大面积填充，不用颜色替代层级。
- 两套主题的对比度数值随实际色值复核；换色必须重新测，不得凭感觉。

## 9 缩放

- **界面缩放 100% / 125% / 150% / 200%**：八档字号按比例放大；100% 时最小 10px，200% 时最小 20px 物理像素。
- **图像缩放（如 200%）不改变界面字号**：画布放大的是样本，不是 HUD 与档案。
- 10px 是硬下限；窗口变窄、语言变长、缩放变大时，**先换行、先折叠次要字段、先加宽面板，不缩字**。
- 数字、单位、读数一律不截断、不省略；表格列宽不足时改为两行（标签上、值下），单位跟随数值同一行。
- 文件名可中间省略，但必须保留扩展名与末尾至少 4 个字符；路径可省略中间段，不省略文件名。
- 200% 时右栏至少保留 360px 内容宽；不足则五段纵向滚动，不并排压缩。

## 11 禁止清单

- 禁止字重 700；禁止用 600 伪装 700。
- 禁止斜体、oblique、描边字、阴影字、发光字。
- 禁止小于 10px 的文字，包括键位提示、角标、脚注、单位。
- 禁止全大写中文；禁止把 `text-transform: uppercase` 作用在含中文的元素上。
- 禁止 10px 中文：单位和快捷键等 10 档只给拉丁与数字，中文脚注最低 11。
- 禁止用颜色代替层级；灰度后必须仍能读出主次。
- 禁止给中文加字距、两端对齐、全角空格撑距。
- 禁止全角数字/字母；禁止用 `um2`、`um` 代替 `µm²`、`µm`。
- 禁止截断、省略数字、单位与读数；禁止用 `…` 隐藏测量值。
- 禁止同一窗口出现第九档字号；禁止为塞进面板而缩字。
- 禁止下载字体、内嵌 Web Font、用 CDN 字体。

## 12 HTML 对照 token（仅 specimen）

以下只为 `type-specimen.html` 的视觉复现，不是 Avalonia 契约；落地以第 2–4 节的 DIP 设计值为准。

## 13 验收

1. **并排遮色**：遮住 21/22 的颜色，字号、字重、行高逐项一致。
2. **灰度**：转灰度后主次仍成立，没有只靠颜色区分的信息。
3. **200%**：界面放大到 200%，最小字号 20px 物理像素，无截断、无重叠。
4. **CSV**：界面与 CSV 的小数位、数值一致；CSV 无千分位、无单位。
5. **中文**：中文没有字距、没有 faux bold、没有全角拉丁；中英/数字/单位空格符合第 6 节。
6. **下限**：全屏搜索 10px 以下文字，结果必须为零。

## 14 交接边界

本文是**设计定义**，不是实现方案；只要求落在 Avalonia 路线内，不规定它怎么落。

**设计负责**：字体家族的意图、八档字号与行高、字重规则、字距、数字与单位规则、中英混排、色层与对比度、缩放后的字号行为、第 13 节的验收语言。

**架构负责**：Avalonia 资源键与类型、字体回退的配置、AtomUI 令牌的钉死、应用内缩放的实现机制、控件模板覆盖、运行期验收工具，以及 Windows/macOS/Linux 的实测。

**不在本文**：SDK 与构建、包版本、类名与控件名、XAML 写法、验收脚本。`typography-avalonia.md` 是落地参考，由架构维护，不是设计契约；两者冲突时以本文为准并回写参考。
