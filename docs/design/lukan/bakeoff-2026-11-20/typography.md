## 0 三条前提

1. **四档。** 工作窗口只有 11、13、16、20 四档；没有第五档，不靠加档解决层级。
2. **两版同字，只换色。** 21 与 22 的字号、字重、行高、字距逐项相同；明暗只改颜色与材质。
3. **层级靠字号、字重、色层与留白。** 灰度后仍须成立；颜色只做辅助。

### 0.1 载体说明

本文是**设计定义**，数值按 DIP 计（100% 时 1 DIP = 1 px），不是 CSS 像素；HTML 字样页只是视觉参照。Avalonia 的落地由架构负责，映射见 `typography-avalonia.md`；本文只定数值、角色与验收。

## 1 字体家族

只用系统字体，不下载、不内嵌。

| 用途 | 字体 |
| :--- | :--- |
| 界面无衬线 | Segoe UI Variable Text → Segoe UI → 平台默认无衬线 |
| 中文回退 | Microsoft YaHei UI → PingFang SC → Noto Sans CJK SC |
| 数字等宽 | Cascadia Mono → Consolas → 平台等宽 |

- 中文不进等宽列：等宽族没有汉字，混入即错位。
- 不合成粗体与斜体；系统没有的字重不假装有。

## 2 字号阶

| 档 | 字号 / 行高 | 用途 | 出现位置 |
| :--- | :--- | :--- | :--- |
| 20 | 20 / 28 | 主读数，一屏一个 | 当前 ROI 的关键值；不用于标题、按钮与强调 |
| 16 | 16 / 24 | 面板标题 | 「标本档案 / Specimen Record」 |
| 13 | 13 / 20 | 正文、菜单、字段值、六项读数、按钮、窗口标题（拉丁 600） | 全局默认 |
| 11 | 11 / 16 | 字段标签、段标题、表头、单位、状态栏、工具提示、快捷键、哈希 | 全局下限 |

- 主读数只给一个；六项 Results 同为 13，不因重点单独放大。
- 字号不随面板宽度缩小；空间不足先折叠、换行、加宽。
- 11 是硬下限，中文也用它；没有 10 档。

## 3 字重

| 字重 | 用途 | 限制 |
| :--- | :--- | :--- |
| 400 | 中文全部；正文、字段值、读数、单位、菜单 | 默认 |
| 600 | 拉丁窗口标题、拉丁面板标题、拉丁段标题、拉丁表头、选中项 | 只用于拉丁；中文请求 600 会落到 700，禁用 |
| 700 / 斜体 / 描边 | **禁止** | 任何位置不得出现 |

- **中文只有 400**：YaHei、PingFang 没有中间字重；中文层级靠字号、色层与留白。
- **拉丁的 500 与 600 在 Windows 上是同一笔画**，不用 500，也不拿 500/600 当两级。
- 读数不加粗；强调靠 20 档与 T1。

## 4 行高与字距

| 档 | 字号 / 行高 | 字距 |
| :--- | :--- | :--- |
| 20 | 20 / 28 | −0.20 DIP |
| 16 | 16 / 24 | 0 |
| 13 | 13 / 20 | 0 |
| 11 | 11 / 16 | 0；拉丁大写 +1.10 DIP |

- 中文不加字距，不用两端对齐，不用全角空格凑距。
- 拉丁大写段标题与表头可加 1.10 DIP；中文并列部分保持 0。
- 行高是绝对值，不是比例；Avalonia 侧按 DIP 写。

## 5 数字规则

- 测量值、坐标、像素值、缩放、校准、时间、哈希、版本号用等宽 400。
- 数字列右对齐，同列固定小数位；小数对齐靠等宽与右对齐，不靠字体特性。
- 单位不进数字列：数字右对齐到列边，单位另起 11 档左对齐，T2/T3 色层。
- 读数与数字列**不加千分位**；正文需要分隔时用不换行空格，不用窄空格。
- 负数界面用 U+2212，CSV 用 ASCII `-`；百分数不加空格；数字与 SI 单位一个不换行空格。
- 界面与 CSV 共用小数位：Area/Mean/StdDev/Perimeter 各 1 位，Min/Max 0 位；CSV 无单位、无千分位。
- 等宽列只放数字、拉丁 ID、单位与文件名；出现汉字即错位。

## 6 中英混排

| 边界 | 规则 | 示例 |
| :--- | :--- | :--- |
| 中文 ↔ 拉丁 | 一个普通空格 | `测量 Results`、`当前 ROI` |
| 数字 ↔ 中文量词 | 一个普通空格 | `6 个 ROI` |
| 数字 ↔ SI 单位 | 一个不换行空格 | `1240.5 µm²` |
| 双语标签 | 中文 + 空格 + `/` + 空格 + 拉丁大写 | `身份 / IDENTITY` |
| 百分号 / 角度 | 不加空格 | `200%`、`45°` |

## 8 明暗两套的对比度底线

| 色层 | 亮（面板 `#FFFFFF`） | 暗（面板 `#1C1F23`） | 用途 |
| :--- | :--- | :--- | :--- |
| T1 | `#141619`（18.1:1） | `#E9ECEF`（14.0:1） | 正文、读数、标题 |
| T2 | `#4C5259`（7.9:1） | `#B5BBC2`（8.6:1） | 字段值、状态 |
| T3 | `#6A717A`（4.9:1） | `#8C939B`（5.3:1） | 标签、单位、脚注 |
| Signal | `#B83A24`（5.7:1） | `#D89A4A`（6.8:1） | 当前 ROI、运行中；只做 2px 标与线，不做正文与填充 |

正文与读数不低于 4.5:1，弱化文字不低于 3:1；Signal 不用于正文，不用颜色代替层级。具体表面、线与状态色值以 `color-tokens.md` 1.1 为准，本表只锁文字三层与信号的门槛。

## 9 缩放

- 界面缩放 100% / 125% / 150% / 200%，四档字号按比例重算，最小物理字号不低于 11。
- 图像缩放不改变界面字号；画布放大的是样本。
- 空间不足先换行、折叠次要字段、加宽面板，不缩字。
- 数字、单位、读数不截断、不省略。

## 10 应用映射：21 与 22

| 段 | 排印 |
| :--- | :--- |
| 身份 | 面板标题 16；样本号 13/拉丁 600；标签 11/T3；值 13；位深与校准 13 mono |
| 测量 | 主读数 20 mono；六项 13 mono；单位 11/T2；表头 11；台账行 11 |
| 参数 | 段标题 11；标签 11/T3；值 13；分段控件 13，选中 600 拉丁 |
| 溯源 | 段标题 11；摘要 11 mono T3；展开行 11 |
| 操作 | 段标题 11；按钮 13；快捷键 11 mono T3 |
| 共享 | 窗口标题 13；菜单 13；状态 11；命令面板 13/16 |

两版结构、字段、字号完全一致；朱红与琥珀只作用于 Signal，不改字重与字号。

## 11 禁止清单

- 禁止第五档字号；禁止 10px 与更小。
- 禁止中文 500/600/700；中文只有 400。
- 禁止斜体、描边、阴影字、发光字。
- 禁止给中文加字距、两端对齐、全角空格。
- 禁止用颜色代替层级；灰度后必须仍能读出主次。
- 禁止全角数字与字母；禁止 `um2`、`um` 代替 `µm²`、`µm`。
- 禁止截断、省略数字、单位与读数。
- 禁止下载字体、内嵌字体。

## 13 验收

1. **四档**：全屏搜索字号，结果只落在 11 / 13 / 16 / 20。
2. **并排遮色**：21/22 遮住颜色后，字号、字重、行高逐项一致。
3. **灰度**：灰度后主次仍成立。
4. **200%**：界面放大后无截断、无重叠，最小物理字号不低于 11。
5. **CSV**：界面与 CSV 精度一致；CSV 无千分位、无单位。
6. **中文**：无字距、无 600、无全角拉丁；中英与单位空格正确。

## 14 交接边界

设计负责：四档字号与行高、字重规则、字距、数字与单位、中英混排、色层与对比度、缩放行为、验收语言。

架构负责：Avalonia 资源键、字体回退、AtomUI 令牌、应用内缩放机制、控件模板、跨平台实测与验收脚本。

不在本文：SDK、包版本、类名、控件名、XAML、脚本。
