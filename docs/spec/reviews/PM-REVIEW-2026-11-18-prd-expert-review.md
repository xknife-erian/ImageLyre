# PRD 专家评审记录（2026-11-18）

## 评审对象与方式

对象为 `docs/spec/requirements/product-requirements.md`，起始版本 1.1，评审后迭代至 2.3。评审采用七位第三方角色独立评审、逐轮复核的方式，每位专家只代表本角色发言，不参与实现、与本项目无利益关系。评审分四轮：第一轮全量评审并给出 blocker/major，第二轮核验修订，第三轮终审（仅成像平台技术员返回），第四轮签核；每轮结论均写入本记录，产品方逐条处置并回写文档。

| 角色 | 视角 |
| :--- | :--- |
| 课题负责人（PI） | 科研可信度、可复现、团队口径、采购与长期维护 |
| 日常分析者（博士后/研究生） | 日常操作流、ImageJ 习惯、批处理、性能与自救 |
| 成像平台技术员 | 厂商格式与元数据、部署、大文件、跨平台与升级 |
| 方法开发者（算法/生信） | 插件 API、沙箱、Python、调试与扩展边界 |
| 教学用户（讲师） | 机房部署、免费边界、引导、低配与可访问性 |
| 大厂级桌面软件架构师 | 进程模型、工程格式、性能预算、打包与治理 |
| 高级应用开发工程师 | 需求可实现性、验收可测性、边界与持久化 |

## 第一轮：结构性缺口

七位专家一致判定 blocker，核心意见集中在五处：

1. 可复现链断裂：CSV 与溯源互相排斥，工程验收只验界面状态不验数值。
2. 对照基线不可执行：ImageJ 版本、测量选项、容差与验证报告均未钉死。
3. 团队与实验室口径缺失：配置档、只读复核、整目录重定位、版本漂移均无需求。
4. 部署与离线缺口：安装、静默部署、离线全量包、签名与网络分级缺失或自相矛盾。
5. 插件与工程契约缺失：沙箱数据通路、Python 运行时、工程格式、插件 API 版本与调试均未定义。

另有优先级与附录计数错误（插件体系实为 9 条 P1、总数 78 而非 77），以及大量不可验收措辞。

## 第二轮：复核 2.0

2.0 补齐了溯源 sidecar、验证报告、团队配置、安装部署、网络分级、插件数据与 API 契约、工程格式、跨平台一致性与可访问性，计数修正为 131 条。第二轮仍留下三类问题：

- 测量基线仍用「M1 冻结」「报告中给出」占位，附录 B 没有选项表。
- CSV 与 sidecar 的写入口径冲突（坏帧标记与溯源仍要求写进 CSV）。
- 进程拓扑与架构基线 §6.2 冲突，且 BioFormats 内置没有 ADR 闭环。

## 第三、四轮：收口

产品方新增 ADR-0004（沙箱像素数据通路与进程拓扑）与 ADR-0005（BioFormats 内置），基线升至 1.4；PRD 2.1 钉死附录 B.1 测量基线（ImageJ 1.54f、选项集、列序、n−1、256 桶、A/B/C 容差与 fixture 先行），插件最小底座与无头入口升 P0，VAL-004 收窄并移至 M4，补运行时自带、课程实验清单与可访问性指标。第四轮仍有七条单点 major，逐条处置如下：

| 专家 | 问题 | 处置 |
| :--- | :--- | :--- |
| PI | MEAS-004 仍允许诊断扩展列，与「CSV 只含基线列」冲突 | 删除扩展列条款，诊断与质量信息只写 sidecar |
| 日常分析者 | P0 的厂商解码与栈投影依赖 P1 的 PLUG-003 | PLUG-003 升 P0，范围限定为沙箱执行、取消、崩溃隔离与最小权限 |
| 成像平台技术员 | 组合预算按位深而非字节计算，与 IO-011「继续」冲突 | 公式改为字节；删除 IO-011 的「继续」选项 |
| 方法开发者 | 同上，且 PLUG-013 拓扑未进 P0 | PLUG-003 纳入每插件一进程与越权拒绝验收 |
| 教学用户 | 离线全量包无体积上限，体积指标无门禁 | SYS-011 补 ≤2.0 GB；§9 与 §12 增加体积实测 |
| 架构师 | 基线 §10.1 未按 ADR-0004 区分主进程内与沙箱插件；权限验收缺失 | 基线 §10.1 拆分两类登记并补权限准入；PLUG-003 纳入越权验收 |
| 高级应用开发工程师 | §6.5 容差未覆盖中位数、偏度、峰度、X/Y、FeretAngle、MinFeret | 补 D/E/F 类并回填 B.1 统计公式 |

## 结论

截至 2.3，第一至第四轮提出的 blocker 均已关闭，剩余意见为单点可测性修订，已逐条落回文档。最终签核轮结果见文末。

## 最终签核

签核对象为 PRD 2.3、基线 1.4 与 ADR-0004/0005。七位专家全部给出 sign_off，其中五位在第五轮直接签核，两位在第六轮针对两处文本修订复核后签核。

| 专家 | 签核轮次 | 结论 | 保留意见 |
| :--- | :--- | :--- | :--- |
| 课题负责人（PI） | 第六轮 | sign_off | B.1 与 §6.5 容差类别对齐后无保留 |

| 教学用户 | 第五轮 | sign_off | 2.0 GB 与 5 GB 门禁需真机实测回填 |
