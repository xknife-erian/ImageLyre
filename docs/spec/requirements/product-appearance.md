# 产品外观：第一直觉

| 版本 | 日期 | 状态 | 作者 | 说明 |
| :--- | :--- | :--- | :--- | :--- |

| 0.2 | 2026-11-20 | 现行 | lukan | 选定稿 20 为默认亮主题、稿 19 为暗主题；两者必须同构，只换颜色、明度与材质 |

## 1 一句话

**像一张被灯照亮的实验台：样本是唯一发光的东西，工具伸手可及，其余都安静地退到暗处。**

用户第一眼不该说「功能真多」，而该说「把图放上去」。第一眼之后，他要相信这台东西不会挡在他和样本之间。

## 2 两条前提

### 2.1 它是桌面软件，不是网页

这是一件安装在电脑上的软件，Windows、macOS、Linux 是同一个产品的三个端，没有「网页版」与「客户端」之分，也不是把网页装进一个窗口。

- 有窗口、有菜单、有状态栏，能缩放、能最小化、能多开；文件从系统对话框进出，拖拽、右键、快捷键、多显示器都是默认能力。
- 启动是进程，关闭是退出；本地文件、本地缓存、离线可用，核心路径不转圈等网络。
- 不做浏览器那套：没有地址栏、没有页面级滚动、没有「路由跳转」，也不用移动端的汉堡菜单与全屏浮层。
- Core 1.0 先把 Windows 做扎实，只发 Windows 正式版；macOS 与 Linux 随后跟进。但外观、菜单逻辑与术语从现在起就按三端共用设计，不做只有 Windows 才成立的捷径。

判断标准很简单：把截图放进操作系统里，它应该像别的桌面软件一样有窗框、菜单与状态，而不是像一张网页。

### 2.2 与 ImageJ 有渊源，但必须完全超越

渊源不是包袱，是入场券：老用户进来要先认路。菜单名、Results、ROI 手势、测量口径、`.roi` 往返、常用快捷键，这些锚点保留；锚点变了，要当场告诉他以前是什么、现在是什么。

超越不是把 ImageJ 画得更漂亮，而是把它没做好的事做对：零模态、可逆、可解释、可复现、插件即插即用、Agent 当同事、大图不卡、排版能读。

两条同时成立才算数：让老用户第一眼认出来，第二眼不想回去。只做到第一眼是换皮，只做到第二眼是背叛。

## 3 远看、近看、用起来

| 视角 | 应该看到什么 |
| :--- | :--- |
| 远看 | 一块暗下去的台面，一张被照亮的图，一条细得几乎看不见的边 |
| 近看 | 线细、字清、数齐；没有装饰，没有第二层光泽 |
| 用起来 | 手比眼快：想画就画，想测就测，不用先找按钮 |

远看要有分量，近看要有分寸，用起来要有速度。三者缺一，外观就只是皮肤。

## 4 第一直觉的三个瞬间

### 4.1 第一秒：光

屏幕不是「一个软件界面」，是一间调过光的房间，中间一张图被照亮。没有欢迎页，没有仪表盘，没有「新建项目」。

浅色不是白底黑字，是白天靠窗的台面；深色不是黑底白字，是暗房里只开了一盏观片灯。两者都是「有光的房间」，不是反色关系。

### 4.2 第三秒：秩序

图的四周只有三样东西：比例尺、坐标、当前缩放。工具栏窄，贴着边；Results 在下方，像一条安静的纸带。用户能一眼指出「从这里开始」，不需要读完整个屏幕。

界面上的每一样东西都要能回答「它现在为什么在这里」；答不上来的，就该退场。

### 4.3 第三十秒：手

用户已经在画 ROI，参数在画布边缘改，数字当场变；没有对话框跳出来要求「先选择图像类型」，也没有向导要求「下一步」。

第一直觉的终点不是「好看」，是「我已经在干活了」。

## 5 气质五条

| 它像 | 它不像 |
| :--- | :--- |
| 一间调过光的房间 | 一块塞满卡片的仪表盘 |
| 一支顺手的好笔 | 一台需要培训的机器 |
| 一张干净的实验记录纸 | 一个 Web 后台 |
| 一件精密但不怕碰的仪器 | 一件怕碰的展品 |
| 一个安静的同事 | 一个抢话的助手 |

「精密但不怕碰」是这套外观最难的部分：要让人相信数字是准的，也要让人敢乱点、敢撤销、敢试。

## 6 五个外观决定

1. **样本最大**：打开一张图，图像占可视面积的主体；面板默认收起，需要时滑出，不需要时退场。界面不该比样本更亮、更花、更抢眼。
2. **只有一处发光**：全屏只有一个信号色，只给「选中、警告、正在运行」；其余是中性灰阶。没有第二套强调色，没有装饰性渐变。
3. **像玻璃与纸，不像塑料**：边界用细线，层次用留白与明度，不用圆角卡片、投影与玻璃拟态堆叠。面板是墙上的搁架，不是浮在空中的窗。
4. **数字是读数**：结果区用等宽数字、右对齐、单位弱化；一列数字要能竖着扫。数字不滚动、不弹跳、不做入场动画。
5. **动效只解释空间**：面板从它所属的那条边出现，图从它来的方向进入；没有弹跳、旋转、粒子。超过两秒的任务必须有真实进度与取消。

## 7 密度与节奏

- 常用动作一只手够得着；低频参数渐进披露，不一次摊开。
- 一屏只服务一个任务：看图、选区、测量、对比，不把四件事塞进同一条工具栏。
- 空白是功能，不是浪费；但空白只用来让样本呼吸，不用来装点门面。
- 中文与英文并排时不打架：数字与单位对齐，术语不缩写，句子不为了塞进按钮而被砍断。

## 8 第一次见 ImageJ 用户

老用户看到的不是一套陌生界面，而是熟悉的锚点被搬进了一间更好的房间：菜单名还在，Results 还在，ROI 手势还在；房间更安静，光更准，手更顺。

第一眼「还是那套」，第二眼「顺手多了」。这两句必须同时成立：只剩第一句是换皮，只剩第二句是背叛。

## 9 反面清单

- 医疗监护仪式的深色仪表盘，红黄绿报警灯常亮；
- Web 后台式的卡片墙、面包屑与侧边导航树；
- 复古示波器、金属拉丝、纸张纹理与「科学仪器」刻板印象；
- 游戏 HUD 式的发光边框、扫描线与装饰性网格；
- 浏览器套壳：地址栏、页面级滚动、路由跳转、移动端汉堡菜单；
- AI 聊天侧栏占住画布，或把「智能」做成漂浮气泡；
- 为了「科技感」使用蓝紫渐变、玻璃拟态与无意义动效。

## 10 怎样算做到

| 检验 | 通过的样子 |
| :--- | :--- |
| 三秒测试 | 给一张陌生图，用户三秒内知道这是看图与测量的地方，并能指出开始的位置 |
| 遮标测试 | 遮住 logo 与标题，仍认得出是同一款软件；同时不会被误认成 ImageJ |
| 关闭测试 | 关掉软件后，记得的是图与数字，不是界面 |
| 迁移测试 | ImageJ 老用户第一眼说「还是那套」，第二眼说「顺手多了」 |
| 窗口测试 | 把截图放进操作系统里，有窗框、菜单与状态，像桌面软件，不像网页 |
| 断网测试 | 拔掉网线，打开、校准、ROI、测量、导出仍能完成 |
| 渊源测试 | ImageJ 老用户能指出三处熟悉的锚点，也能指出三处明显更好的地方 |
| 截图测试 | 任意一张工作截图放进论文或汇报，不显得像后台系统 |

## 11 与其它文档的关系

两条前提是本文的地基：桌面软件，以及与 ImageJ 的渊源和超越；任何视觉选择与之冲突时，先改选择。PRD §4.1 是视觉语言的条款层，本文是它上面的直觉层；本文不规定色值、字号、圆角与控件，那些属于设计与实现。两者冲突时，以本文的气质与 PRD 的验收语言为准。

## 12 选定方向（2026-11-20）

竞标收口：**稿 20（纸白标本档案）为默认亮主题，稿 19（深色标本档案）为暗主题。**

统一骨架后为 **21（亮）与 22（暗）**；排印 2.0 落地为 **23/24**；排印加间距落地后为 **26/27**；去复古、选中改标后为 **29**；信号标随轴后为 **30（亮）**；暗色按 30 结构收口后为 **31（暗）**。**30 与 31 是当前基准**：同结构、同字段、同入口、同状态规则，只有颜色与材质不同；19–29 保留为来路。

窗口档在 `docs/design/lukan/bakeoff-2026-11-20/`，编号见 `versions.md`：19–31。字号、字重、行高、数字与中英混排见 `typography.md` 2.0，间距与栅格见 `spacing.md`，颜色与状态见 `color-tokens.md` 1.3；三份基线两版必须逐项一致。

## 13 交互状态（2026-11-20）

状态不是控件的装饰，是同一套语法在不同形状上的投影；完整语法见 `docs/design/lukan/bakeoff-2026-11-20/state-model.md`。

- **五态五通道**：当前（画面对象）= 沿形 2px 线；选中 = 轴上的 2px 轨 + 一档中性底；焦点 = 贴底下划线 1px；悬停 = 只换底；编辑 = 光标 + 下划线。
- **不反白、不色字、不填充**：信号色只做线，不做文字色，不做色块；选中、当前、焦点都不改变文字颜色。
- **焦点不是框**：键盘落点永远是一条下划线，表格落在当前行底边，不套单元格、不套整行。
- **二元选择没有开关**：设置与表单用复选框，菜单用勾选，行内参数用两段式分段；不出现轨道加旋钮的开关。
- **一屏一处「当前」**：信号之外不再加第二个强调色；灰度截图后仍要能看出谁被选中、谁有焦点。

色值见 `color-tokens.md` 1.3，控件规格见 `controls.md`，视觉基准见稿 30。
