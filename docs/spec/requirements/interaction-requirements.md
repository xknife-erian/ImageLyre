# ImageLyre 交互需求

| 版本 | 日期 | 状态 | 作者 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 0.1 | 2026-11-20 | 现行 | lukan | 15 条主交互流：场景、步骤、反馈、失败、键盘等价与验收语言；与 CORE-01~15 一一对应 |

## 0 读法

- 本文回答「用户怎么把事做完」，不回答「控件长什么样」；界面结构见 `main-window-spec.md`，视觉基线见稿 30/31。
- 每条流程固定七段：场景、前置、主路径、反馈、失败与恢复、键盘等价、验收。
- 验收语言必须是用户能感知、可复述的结果，不写技术测试。
- 与 CORE 一一对应：`IX-01` 对 `CORE-01`，依此类推。

## 1 交互模型

| Key | 值 | 说明 |
| :--- | :--- | :--- |
| `model.object` | 图像、ROI、测量、版本 | 用户操作的四类对象 |
| `model.selection` | 单选为主，多选只用于批次 | 画布内一次一个 ROI |
| `model.command` | 菜单、命令面板、快捷键、右键 | 同一命令四个入口，行为一致 |
| `model.undo` | 所有会改变结果的动作可撤销 | 视图缩放不算结果 |
| `model.feedback` | 就地反馈，不弹窗 | 状态栏、画布边、右栏 |
| `model.keyboard` | 每条主路径都有键盘等价 | 见各流程 |

## 3 主交互流

### IX-01 第一次打开就能开始

- **场景**：新用户第一次启动，没图、没配置。
- **前置**：安装完成，无网络也可。
- **主路径**：启动 → 空态三入口（打开文件 / 打开示例 / 最近文件）→ 选示例 → 图与三步提示出现 → 直接可画 ROI。
- **反馈**：启动到可操作 ≤3 秒；示例自带校准；三步提示贴在画布边，不遮图。
- **失败与恢复**：示例缺失 → 提示「示例未随包安装」并给打开文件；最近文件失效 → 灰显并标注「文件已移动」。
- **键盘**：Tab 到三入口，Enter 打开；Ctrl+O 直接打开。
- **验收**：新用户不看文档一分钟内打开第一张图；首启没有强制向导与空窗。

### IX-02 打开标准 TIFF

- **场景**：用户拖入或打开一张 16 位带校准 TIFF。
- **前置**：文件可读。
- **主路径**：拖入/打开 → 进度 → 图出现 → 标题显示文件名 → 状态栏显示位深、尺寸、校准。
- **反馈**：超过 300ms 显示进度；首帧先出，后续帧继续解码；不弹格式选择框。
- **失败与恢复**：损坏 → 内联条说明原因 + 重试/换文件；不支持格式 → 说明「首版只支持 TIFF/BigTIFF」并给插件入口。
- **键盘**：Ctrl+O；Esc 取消加载。
- **验收**：打开后位深、尺寸、校准与文件一致；损坏文件不静默失败。

### IX-03 看图：缩放、平移、探针

- **场景**：用户检查图像细节。
- **前置**：图已打开。
- **主路径**：滚轮以光标为中心缩放 → 空格拖拽平移 → 悬停读像素 → 0 适应窗口、1 到 100%。
- **反馈**：缩放比例实时显示；探针显示坐标、像素值、通道、Z/T；缩放不重写像素。
- **失败与恢复**：超出图像边界时探针显示越界；缩放到底不弹提示，按钮态变灰。
- **键盘**：+ / − / 0 / 1；方向键微移视图；空格拖拽。
- **验收**：探针读数与 ImageJ 一致；缩放与平移不改变原始数据。

### IX-04 校准

- **场景**：无校准图需要手动设比例尺；有校准图需要核对。
- **前置**：图已打开。
- **主路径**：图像 → 校准 → 读文件校准或输入已知距离 → 画一条已知长度线或填数值 → 单位确认 → 全图生效。
- **反馈**：校准链显示「0.5 µm/px = 10 µm / 20 px」；未校准时测量用像素单位并黄色提示。
- **失败与恢复**：数值非法 → 就地红字与范围提示；取消 → 回到原校准；校准错误可撤销。
- **键盘**：Ctrl+K 搜「校准」；Tab 到输入框，Enter 应用。
- **验收**：同一已知距离，Lyre 与 ImageJ 校准一致；无校准测量明确提示。

### IX-05 画 ROI 与改顶点

- **场景**：用户在图上圈一个区域。
- **前置**：图已打开。
- **主路径**：选矩形/多边形 → 画 → 双击或 Enter 闭合 → 拖顶点调整 → 整体移动 → Delete 删除。
- **反馈**：绘制时显示尺寸与坐标；闭合后出现主读数标签；顶点命中区 ≥8px。
- **失败与恢复**：画到一半 Esc 取消；越界顶点吸附边缘并提示「已贴边」；误删可撤销。
- **键盘**：R 矩形、P 多边形、Enter 完成、Esc 取消、Delete 删除、Alt 点边加点。
- **验收**：画、改、存、再打开，几何与面积不丢；`.roi` 往返与 ImageJ 互开。

### IX-06 测量并读六项

- **场景**：用户对一个 ROI 出数。
- **前置**：有 ROI，校准已读或已设。
- **主路径**：ROI 完成 → 自动测量或 Ctrl+M → 右栏六项出现 → 点任一数字看来路。
- **反馈**：六个数字同字号右对齐；单位降级；台账显示 ROI 数；测量 ≤200ms。
- **失败与恢复**：无 ROI → 测量禁用并提示「先画一个选区」；计算失败 → 内联条 + 重试。
- **键盘**：Ctrl+M；Tab 到结果表读行。
- **验收**：单 ROI 六项与基线在容差内；点数字能看到来源。

### IX-07 改参数，结果当场变

- **场景**：用户改单位、小数位或阈值。
- **前置**：已有结果。
- **主路径**：右栏参数段改一项 → 六项与单位当场重算 → 溯源记下这次改动。
- **反馈**：≤200ms 更新；数字不跳动、不做动画；改后状态标「未保存」。
- **失败与恢复**：非法值 → 就地提示并保持上一有效值；Esc 撤回本次输入。
- **键盘**：分段控件方向键切换；输入框 Enter 应用、Esc 取消。
- **验收**：改一个参数，六个数与单位同时正确变化；无对话框。

### IX-08 导出 CSV 与 sidecar

- **场景**：用户把结果交给同事复现。
- **前置**：至少一条结果。
- **主路径**：Ctrl+E → 底部抽屉 → 确认路径、列、sidecar → 导出 → 状态栏给路径。
- **反馈**：预览前 3 行与 CSV 一致；成功后通知中心可打开文件与目录；失败给原因。
- **失败与恢复**：同名覆盖需显式确认；只读目录 → 换路径；导出中断 → 清理半成品。
- **键盘**：Ctrl+E 打开；Ctrl+Enter 导出；Esc 取消。
- **验收**：同事拿导出能按 sidecar 原样重跑；CSV 列与 ImageJ 对齐。

### IX-09 撤销、自动保存、恢复

- **场景**：误操作；或应用被强杀。
- **前置**：有结果或 ROI。
- **主路径**：Ctrl+Z 撤销 → 状态与结果回退 → Ctrl+Y 重做；自动保存每 ≤5 秒写一次；重启后恢复最后一笔有效操作。
- **反馈**：撤销后数字与画布同步；标题脏标记消失；恢复时状态栏提示「已恢复到 10:42」。
- **失败与恢复**：恢复失败 → 给恢复点列表与「从空白开始」；自动保存失败 → 状态栏常驻提示。
- **键盘**：Ctrl+Z / Ctrl+Y；恢复对话框可用键盘。
- **验收**：强杀后恢复 ROI、结果、校准与视图，结果逐值一致。

### IX-10 结果版本、对比、回退

- **场景**：用户想比较两次测量，或回到旧版本。
- **前置**：至少两个版本。
- **主路径**：右栏切「历史」→ 选两版 → 对比 → 标出变化与原因 → 回退 → 生成新版本。
- **反馈**：差异逐项标新增/变化/删除；回退留痕、可再前进；源图像不变。
- **失败与恢复**：版本损坏 → 标记不可用并保留其余；回退失败 → 保持当前版本并报因。
- **键盘**：历史列表 ↑↓；空格选中对比；Ctrl+Z 撤销回退。
- **验收**：任选两版可对比并解释差异；回退/前进留痕。

### IX-11 切主题与切语言

- **场景**：用户在暗环境工作，或需要英文界面。
- **前置**：无。
- **主路径**：标题栏点主题/语言 → 即时切换 → 布局不跳、数据不变。
- **反馈**：切换 ≤200ms；不重启；数字、单位、CSV 不随语言变。
- **失败与恢复**：缺翻译 → 回退中文并记录；主题资源缺失 → 保持当前主题并提示。
- **键盘**：Ctrl+K 搜「主题」「语言」；Enter 切换。
- **验收**：切换不重启、无半套主题、页面不混用语言。

### IX-12 装一个插件

- **场景**：用户从本地包安装一个格式插件。
- **前置**：有插件包。
- **主路径**：插件 → 插件中心 → 选包 → 看来源/能力/权限 → 安装 → 菜单与命令面板出现 → 立即可用。
- **反馈**：安装进度、成功后通知；卸载后入口立即消失；失败回滚。
- **失败与恢复**：签名/兼容性不通过 → 安装前阻断并说明；插件崩溃 → 隔离，主程序不受影响。
- **键盘**：Ctrl+K 搜「插件」；Tab 到安装。
- **验收**：装完即用、无需重启；卸载干净；崩溃不波及主程序。

### IX-13 从 ImageJ 来

- **场景**：老用户第一次启动，选择「我从 ImageJ 来」。
- **前置**：无。
- **主路径**：首启选择 → 布局与键位切换 → 打开旧图 → ROI/校准导入 → 对照表可查 → 完成第一次测量。
- **反馈**：保留 Analyze、Results、ROI 手势；改动处首次触发提示「以前是 X，现在是 Y」。
- **失败与恢复**：`.roi` 不兼容 → 说明原因与替代路径；对照表搜不到 → 给反馈入口。
- **键盘**：保留 ImageJ 常用键位；Ctrl+K 可搜旧菜单名。
- **验收**：五分钟完成第一次测量；二十个高频动作 ≥95%；改动 100% 可查对照。

### IX-14 不开界面做一次分析

- **场景**：Agent 或脚本跑一批图。
- **前置**：CLI 可用。
- **主路径**：发现能力 → 打开 → 校准 → ROI → 测量 → 导出 → 读 JSON 与退出码。
- **反馈**：每步有结构化结果；失败可判重试或改输入；结果与桌面一致。
- **失败与恢复**：缺权限/路径只读 → 明确错误码；中断 → 可重跑且不污染输入。
- **键盘**：不适用；终端可用。
- **验收**：无显示环境完成一次分析；结果与桌面逐值一致。

### IX-15 不用鼠标完成一次测量

- **场景**：键盘用户或 RSI 用户。
- **前置**：应用已启动。
- **主路径**：Tab 到画布 → 键盘创建矩形 ROI → 输入校准 → Ctrl+M → Tab 读结果 → Ctrl+E 导出。
- **反馈**：焦点始终可见（下划线）；快捷键提示在菜单与命令面板可查；不出现只靠鼠标的步骤。
- **失败与恢复**：焦点丢失 → Esc 回画布；快捷键冲突 → 命令面板仍可达。
- **键盘**：全路径，无鼠标依赖。
- **验收**：不用鼠标完成打开→校准→ROI→测量→导出；缩放不截断。

## 4 横切规则

| Key | 值 | 说明 |
| :--- | :--- | :--- |
| `feedback.press` | ≤100ms | 按下即有视觉反馈 |
| `feedback.recalc` | ≤200ms | 改参数到数字更新 |
| `feedback.progress` | >2s 必须给进度与取消 | 加载、导出、批处理 |
| `undo.scope` | 所有改变结果的动作 | 视图缩放不算 |
| `undo.depth` | ≥50 步或 100MB | 超出降级并提示 |
| `autosave.interval` | ≤5s | 空闲也写 |
| `recovery.time` | ≤2s 回到最后一笔 | 强杀/断电后 |
| `error.copy` | 发生了什么 / 影响什么 / 怎么退回 | 每条错误三句 |
| `language` | 切换不重启，数字不变 | 中英完整 |
| `modal` | 只有设置是模态 | 其余就地 |

## 5 非目标

- 不做批处理编排、3D、反卷积、厂商格式、团队协作、云端。
- 不做多步向导、欢迎页、强制配置。
- 不把交互升级做成可选项；旧路径可以退场，但要有过渡与对照。
