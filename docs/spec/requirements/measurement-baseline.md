## 1 适用范围

本文件对桌面、CLI 与批处理三条路径同时生效，覆盖 Core 1.0 的 CORE-06（六项测量与 Results）与 CORE-07（CSV 与 sidecar），并作为 M1a 编码前必须冻结的前置条件；不覆盖颗粒分析、共定位、3D 与厂商格式的专有元数据口径，这些能力在插件评审时另行引用本文件的容差分类。

| 项 | 基线值 |

| ImageJ | 1.54f 官方发行版，只认 Wayne Rasband 官方包，Fiji 只用于插件盘点、不作为测量基线 |

## 3 测量选项集

以下选项逐项冻结，执行时不得临时改动；M1a 只使用 Area、Mean、StdDev、Min、Max、Perim. 六列，其余列保留在 fixture 中供后续版本使用，执行时不得删列。

| 类别 | 基线值 |
| :--- | :--- |
| 选项 | Area、Mean、StdDev、Min、Max、Perim.、IntDen、Median、Skew、Kurt、X、Y、Feret、FeretAngle、MinFeret、Circ.、N |
| 数值格式 | 小数位 3；科学计数法关闭；NaN 空单元开启 |
| 开关项 | Limit to threshold 关闭；Invert Y 关闭；Black background 关闭；Redirect 无 |
| 校准 | 每张图按黄金数据集的标定值单独 Set Scale，不沿用上一张图的校准 |

## 4 统计口径

面积与像素计数按整数像素统计；标准差取样本标准差（`n−1`）；NaN 像素不计入统计，`N` 列记录有效像素数；浮点累加一律使用双精度；偏度取 `m3/m2^1.5`、峰度取 `m4/m2^2−3`，两者按总体矩（除以 `n`）计算；自动阈值固定 256 桶，像素值大于或等于阈值判为前景，阈值向下取整到桶边界。

标注单位时，物理单位由校准决定，像素单位只在无校准或显式切换时出现，两种单位不得在同一列混排，因为混排会让同一份 CSV 的数值失去可比性。

## 5 Results 与 CSV 列序

Results 表头与 CSV 表头逐字一致，列顺序按 §3 的选项顺序，不插入界面专用列，也不把诊断信息写进 CSV；诊断、质量标记与来源信息只写 sidecar，CSV 保持基线列。

## 6 容差与判定

| 类别 | 内容 | 判定 |
| :--- | :--- | :--- |
| A | 二值掩膜、像素计数 | 掩膜坐标集合哈希逐图完全一致 |
| B | 面积、均值、标准差、最小、最大、积分密度 | `abs(a−b) ≤ max(abs_tol, 1e-6 × abs(b))`，其中面积、最小与最大的 `abs_tol` 为 0，均值、标准差与积分密度为 `1e-9 × (max−min)` |
| C | 周长、Feret、圆度 | 周长差 ≤ `max(1 像素, 轮廓周长 1%)`；Feret 差 ≤ 1 像素；圆度差 ≤ 0.01 |
| D | 中位数 | 整数灰阶逐值一致，浮点按 B 类容差 |
| E | 位置与角度：X、Y、MinFeret、FeretAngle | X、Y、MinFeret 差 ≤ 1 像素；FeretAngle 差 ≤ 0.1° |
| F | 偏度、峰度 | 按总体矩公式计算，差 ≤ `max(1e-3, 1e-6 × abs(b))` |
| 自动阈值 | Otsu 等自动方法 | 掩膜像素差异 ≤ 0.01%，且阈值整数化后与基准相同 |

与 ImageJ 冲突时默认以 ImageJ 为准；若判定 ImageJ 侧错误，须由课题负责人与成像平台技术员会签勘误表并纳入验证报告，不得由实现方单方裁决，因为单方裁决会让下一轮对照失去共同基准。

CLI 与桌面的相互对照沿用同一分类：JSON 指标按 B 类 `1e-9` 相对差判定，CSV 逐字节比较，sidecar 只比稳定字段（排除 timestamp，保留 `buildHash`、`inputSha256`、`threads`、`options`），因为时间戳必然不同而其余字段应当同源。

## 7 文本序列化契约

CSV 默认 UTF-8 无 BOM、逗号分隔、LF 换行、小数点为 `.` 且不随 locale 变化；含逗号、引号或换行的字段用双引号包裹并转义内部引号；NaN 与无穷写为空值；面向 Excel 的 BOM 开关单独提供，且不改变解析后的值；工程清单 JSON 与 sidecar 固定 UTF-8 无 BOM；暴露与持久化的路径统一 NFC，比较前先归一化；跨平台一致性比较解析后的数值，不比较字节。

## 8 与 fixture 的关系

本文件与 `docs/spec/m1/M1-imagej-fixture.md` 构成一对：fixture 提供实测列名、顺序与基准数值，本文件提供判定规则；两者冲突时修订本文件，不得改动 fixture 的选项集，因为选项集一旦按实现需要改动，基准就退化为自证。
