## 1 一句话

**Core 1.0 不是功能大全，是一个可信的分析工作台 + 一个能长插件的底座。**

第一版只保证四件事：打开图能测、测完敢信、老用户能迁、插件能长。其余能力全部让位。

## 2 技术内核：研发前提，不是 P0

| 技术内核 | 作用 |
| :--- | :--- |
| 主题 | 浅色、深色、跟随系统；两套主题完整 |
| 语言 | 中英双语、术语表、切换不重启 |
| 插件宿主 | 安装、启停、卸载、沙箱、权限、能力发现 |
| 宿主壳 | 窗口、画布容器、命令面板、面板、通知、设置 |
| 共享契约 | 文档、会话、溯源、撤销、自动保存——不含任何图像概念 |
| 首选项 | 用户显式配置：可枚举、可搜索的设置项，含默认值、取值范围与版本迁移 |
| 用户习惯 | 软件默默记住：窗口与面板布局（只记上次，不做命名方案）、最近文件、上次使用的值、视图状态；自动保存并在下次启动恢复 |

这七项决定“软件能不能长”，由架构与研发负责。它们不写成产品 P0，也不拿来数需求条数；产品只写用户能感知的结果。

**基座不碰业务**：基座完成后与图像无关，是一个通用桌面外壳；图像、ROI、结果、测量这些契约属于业务，随各自的业务插件定义，不进基座。判断标准只有一条：把 ImageLyre 换成任何一个桌面软件，这套基座仍然成立。

## 3 产品内核：不可退让的四件事

| 产品内核 | 用户感知 |
| :--- | :--- |
| **一次可信分析** | 打开图 → 校准 → 选区 → 测量 → 结果 → 导出，每一步可解释、可复现 |
| **迁移舒服** | ImageJ 老用户五分钟完成第一次测量；习惯有落点，升级有说法，回退有路径 |
| **现代工作台** | 三秒见图、十秒见数、零模态、直接操作、可逆、主题与语言随手可换 |
| **可扩展底座** | 官方套装开箱即用，插件即插即用；菜单是能力的投影，不是硬编码功能表 |

## 4 Core 1.0 的 15 个 P0 产品结果

P0 按“产品结果”计数，不按旧需求 ID 计数。一个结果可以合并多条旧需求；合并后的底层需求在 PRD 4.0 重新编号。

| 编号 | 产品结果 | 覆盖的旧需求 | 验收语言 |
| :--- | :--- | :--- | :--- |
| CORE-01 | 第一次打开就能开始：首启引导、示例数据、最近文件，不强迫配置 | ONB-001、ONB-002、ONB-003 | 新用户不看文档，一分钟内打开第一张图 |
| CORE-02 | 打开标准 TIFF/BigTIFF，保留位深、通道、Z/T 与校准元数据 | IO-001、IO-012 | 打开后位深、尺寸、校准与文件一致 |
| CORE-03 | 画布缩放、平移、适应窗口、1:1，像素探针读数正确 | VIEW-001、VIEW-002 | 缩放不改像素；探针与 ImageJ 一致 |
| CORE-04 | 矩形/多边形 ROI 的绘制、顶点编辑、移动、删除、导入 `.roi`/`.zip` | ROI-001、ROI-002、ROI-004 | 画、改、存、再打开，几何不丢 |
| CORE-05 | 读取与手动设置比例尺，物理单位正确 | CAL-001、CAL-002 | 同一已知距离，Lyre 与 ImageJ 校准一致 |
| CORE-06 | 六项测量与 Results 表：面积、均值、标准差、最小、最大、周长 | MEAS-001、MEAS-003 | 单 ROI 六项结果与基线一致 |
| CORE-07 | 导出 CSV 与 sidecar，保证每一行可追溯、可复现 | MEAS-004、MEAS-007、VAL-001、VAL-002、VAL-003 | 同事拿导出能原样重跑 |
| CORE-08 | 撤销、自动保存、崩溃恢复：强杀后回到最后一笔有效操作 | PROC-008、PRJ-005 | 断电/强杀恢复后结果逐值一致 |
| CORE-09 | 结果版本、对比、回退与前进，源图像不被修改 | PRJ-010、PRJ-011、PRJ-012 | 任选两版可对比并解释差异；回退留痕 |
| CORE-10 | 主题可切换：浅色、深色、跟随系统，两套主题完整 | THEME-001、THEME-002 | 切换不重启，无半套主题，对比度 AA |
| CORE-11 | 中英双语：界面、错误、帮助完整，术语审校，切换不重启 | I18N-001、I18N-002、I18N-003、I18N-004 | 页面无混用；切语言后导出不变 |
| CORE-12 | 插件即插即用：安装/启停/卸载、依赖解析、权限展示、失败回滚 | PLUG-001、PLUG-016、PLUG-017 | 装完即出现在菜单/命令面板/Agent 清单，无需重启 |
| CORE-13 | ImageJ 迁移壳：首启选择、布局与键位、ROI/校准导入、新旧对照表 | 新增 MIG-001（PRD 4.1 落号）；原 VAL-007 并入本结果 | 老用户五分钟完成第一次测量，二十个高频动作 ≥95% |

这 15 个结果覆盖约 40 条旧 P0，并新增一条迁移需求；其余 43 条旧 P0 全部退出 Core 1.0。

## 5 退出 Core 1.0 的东西

### 5.1 进插件

- 图像处理：亮度/对比度、滤波、阈值、形态学、几何变换、栈投影；
- 颗粒分析、共定位、比例成像、3D、反卷积、AI 分割；
- 厂商格式：CZI、LIF、ND2、OIB 等；
- 特殊视图、导出格式、批处理扩展；
- 插件市场、企业插件、脚本运行时。

### 5.2 进首个更新

- 通道合成、伪彩、Z/T 播放、叠加层；
- ROI Manager、多 ROI 批量测量、ROI 组合；
- Results 排序、多行、单位切换、测量选项集；
- 多页 TIFF、PNG/JPG、拖拽导入、大图流式；
- 工程保存/打开、团队配置、复核模式；
- 插件市场、企业授权、遥测；
- CLI 批处理、MCP、插件 CLI 扩展；
- Agent 评测集、更多语言、高对比主题。

### 5.3 明确不做

- 第一版不做 3D、反卷积、AI 分割、厂商格式、团队协作、云端；
- 第一版不做功能大全式菜单；
- 第一版不把核心体验做成可选插件。

## 6 菜单与插件的关系

菜单、命令面板、Agent 工具清单，都是“已安装能力”的投影：

- 官方基础套装默认预装：标准 TIFF、画布/ROI、校准、测量、CSV、迁移包；
- 第三方插件安装后立即出现，卸载后立即消失；
- 没有安装的能力不占菜单位置，只在能力中心可见；
- 插件不能改变核心交互与结果口径，只能扩展能力。

## 7 拍板后的动作

1. 按这 15 个结果重写 PRD 4.0：合并旧需求、重排 P0、删除重复与实现细节；
2. 旧 83 条 P0 逐条标注“Core 1.0 / 首个更新 / 插件 / 不做”；
3. 验收矩阵按 15 个结果重建，不再按旧 ID 堆叠；
4. GitHub Issues 按 15 个结果重开，旧 Issue 关闭或转为插件 backlog；
5. M1 计划只保留支撑 CORE-02~07 与 CORE-08 撤销子集的最小技术闭环，自动保存、崩溃恢复与结果版本由 M2 承接。
