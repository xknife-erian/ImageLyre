## 1 范围

本文只覆盖 M1a 的九条需求：打开标准/ImageJ TIFF/BigTIFF、缩放平移、像素探针、矩形与多边形 ROI、顶点编辑、设置比例尺、六项测量、CSV 导出、黄金数据集对照。M1b 的通道、Z/T、叠加层、ROI Manager、单位切换与 Results 多行排序不在本文；M1b 的交互另起一版，避免一次铺开。

本文是 PRD 4.3 与 `../plans/PM-PLAN-0002-m1-vertical-slice.md` 的交互落点，不改变需求口径；冲突时以 PRD 与计划为准，并回写本文。文中的需求编号沿用 3.4 的实施编号，与 CORE 结果的对应关系以计划 §2.0 的映射表为准。

## 2 窗口骨架

```text
┌──────────────────────────────────────────────────────────────┐
│ File  Edit  Image  Process  Analyze  Plugins  Window  Help   │
├──────────────────────────────────────────────────────────────┤
│ [打开] [适应] [1:1] │ [矩形] [多边形] │ [测量] │ [导出 CSV]  │
├───────────────────────────────────────────┬──────────────────┤
│                                           │ Results          │
│              图像视口                     │ ┌──────────────┐ │
│         （深灰底，图像居中）              │ │ Area  Mean … │ │
│                                           │ │ 5000  128.4  │ │
│                                           │ └──────────────┘ │
├───────────────────────────────────────────┴──────────────────┤
│ X 512  Y 384 │ 128 │ 8-bit │ 100% │ px │ 就绪                │
└──────────────────────────────────────────────────────────────┘
```

- 菜单保留 ImageJ 的八个顶层名称，但 M1a 只启用 File / Edit / Image / Analyze / Window / Help 中与九条需求相关的项，其余置灰并在提示中写「M1b」。
- 工具栏只放 M1a 需要的六个动作：打开、适应窗口、1:1、矩形、多边形、测量；导出 CSV 放 File 菜单，避免工具栏过密。
- 视口底色用深灰 `#2B2B2B`，图像按 100% 或适应窗口居中；不在图像外绘制棋盘格，避免干扰判读。
- Results 面板默认停靠右侧，宽度 ≥ 320px；无结果时显示「尚无测量」。
- 状态栏固定五段：坐标、像素值、位深、缩放、校准单位；最右侧留给临时消息。

## 3 操作流程

### 3.1 打开图像

1. `Ctrl+O` 或 File > Open 打开文件对话框；支持拖拽文件到窗口；最近文件放在 File 菜单底部。
2. 打开中显示进度条与「取消」；超过 2 秒必须出现进度，取消后不得留下锁文件或半开文档。
3. 打开成功后自动适应窗口，焦点进入视口；状态栏显示位深、尺寸与校准单位。
4. 解码失败时弹窗写清「文件、失败原因、下一步」，提供「重试」与「复制诊断信息」；不得静默失败。

### 3.2 缩放与平移

- 滚轮以光标为中心缩放；`Ctrl+=` / `Ctrl+-` 以视口中心缩放；`Ctrl+0` 适应窗口；`Ctrl+1` 100%。
- 空格 + 拖动平移；中键拖动平移；滚动条在图像大于视口时出现。
- 缩放只改变显示变换，不重写像素；状态栏百分比实时更新，1:1 时像素与屏幕一一对应。

### 3.3 像素探针

- 鼠标悬停时状态栏显示 `X, Y`、当前像素值、通道与 Z/T；多通道图像显示元组。
- 浮点图显示 3 位有效小数，16 位显示整数，8 位显示整数；不得用四舍五入改变原值显示以外的语义。
- 鼠标离开视口时保留最后一次读数并置灰，避免状态栏闪烁。

### 3.4 设置比例尺

1. Image > Set Scale 打开对话框；字段为「已知距离、单位、像素数」，像素数默认取当前图像宽度并可编辑。
2. 输入距离必须大于 0，单位不能为空；非法输入时禁用「确定」并在字段下方给出原因。
3. 确定后状态栏单位从 `px` 切换为设定单位，Results 的面积与周长按新校准计算；已有结果不自动重算，需重新测量并在结果表标注校准变更。
4. 提供「移除校准」按钮；移除后回到 `px`。

### 3.5 矩形与多边形 ROI

- 矩形：选择工具后在视口拖动；按住 `Shift` 画正方形；从任意方向拖均可，坐标取整到像素。
- 多边形：单击加顶点，双击或 `Enter` 闭合，`Backspace` 删除上一个顶点，`Esc` 取消未完成的绘制。
- 编辑：拖动顶点改变形状；拖动 ROI 内部整体移动；`Delete` 删除当前 ROI；`Ctrl+Z` 撤销上一次几何变更。
- 越界：ROI 超出图像时按图像边界裁剪；完全在图像外时拒绝创建并提示。
- 视觉：ROI 线用琥珀色 1.5px，顶点为白色 6px 方块；选中态加 1px 外描边，保证深浅背景下都可辨。

### 3.6 测量

1. `M` 或 Analyze > Measure；没有 ROI 时按钮禁用，提示「先画一个选区」。
2. 测量结果追加到 Results；M1a 只支持单 ROI 测量，多 ROI 批量留 M1b。
3. Results 列固定为 Area、Mean、StdDev、Min、Max、Perim.；表头与 CSV 完全一致，不在界面加额外列。
4. 测量在后台线程执行，超过 200ms 显示忙碌指示；测量期间禁止修改 ROI，完成后恢复。

### 3.7 导出 CSV

1. File > Export > Results CSV；默认文件名 `<图像名>_results.csv`，默认目录为图像所在目录。
2. 对话框显示列预览与「UTF-8（无 BOM）」；M1a 不提供 BOM 开关，与 ImageJ 基线一致。
3. 覆盖已有文件需确认；写入失败时保留原文件并提示路径与原因。
4. 导出成功后在状态栏给出文件路径，可点击「在文件夹中显示」。

### 3.8 撤销与取消

- `Ctrl+Z` 撤销最近一次 ROI 几何变更或校准变更；`Ctrl+Shift+Z` 重做。
- 长任务（打开大图、测量）用 `Esc` 或进度条「取消」中止；取消后状态回到操作前。
- 关闭未保存结果时提示「结果未导出」，提供「导出并关闭」「直接关闭」「取消」。

## 4 键位表

| 操作 | 键位 | 说明 |
| :--- | :--- | :--- |
| 打开 | `Ctrl+O` | 与平台惯例一致 |
| 适应窗口 | `Ctrl+0` | ImageJ 习惯优先 |
| 100% | `Ctrl+1` | 同上 |
| 放大 / 缩小 | `Ctrl+=` / `Ctrl+-` | 滚轮为主，键位为辅 |
| 平移 | 空格 + 拖动，或中键拖动 | 与常见图像软件一致 |
| 测量 | `M` | ImageJ 默认 |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Shift+Z` | 平台惯例 |
| 删除 ROI | `Delete` | 与 ImageJ 接近 |
| 取消绘制 | `Esc` | 任何模式下可用 |
| 闭合多边形 | `Enter` 或双击 | 与 ImageJ 多边形操作一致 |

键位表是 M1 默认，不承诺与 ImageJ 完全一致；偏离处在迁移指南登记，M1a 评审时逐条确认。

## 5 状态与错误

| 状态 | 视口 | 工具栏 | 状态栏 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 无图像 | 空白 + 「打开图像」按钮 | 除打开外禁用 | 「未打开图像」 | 拖拽可直接进入加载 |
| 加载中 | 进度条 + 取消 | 禁用 | 「正在读取…」 | 超过 2 秒必须出现 |
| 就绪 | 图像 | 可用 | 坐标/值/位深/缩放/单位 | 默认状态 |
| 绘制 ROI | 图像 + 临时线 | 绘制工具高亮 | 「松开完成」或「双击闭合」 | Esc 取消 |
| 测量中 | 图像 | 测量禁用 | 「测量中…」 | 可取消 |
| 解码失败 | 空白 + 错误块 | 仅打开可用 | 错误摘要 | 提供重试与复制诊断 |

错误文案统一为三段：发生了什么、可能原因、下一步；不写「未知错误」这类无法行动的提示。

## 7 待评审问题

1. ROI 颜色用琥珀色是否足够区分通道伪彩？需要在 M1b 多通道图上看一次。
2. 设置比例尺后是否自动重算已有 Results？本文选择不自动重算，需与科研用户确认。
3. `Ctrl+0` 与 `Ctrl+1` 是否与 ImageJ 完全一致？需要在 Windows 与 macOS 各验一次。
4. 测量在后台线程执行时，Results 追加顺序是否需要锁定？M1a 只有单 ROI，暂不处理并发。
