# ImageLyre.Feature.About

「帮助 → 关于」功能插件：向菜单注册表贡献顶层「帮助」与「关于」项，点击时打开只读的关于窗口。

## 意义

这是菜单贡献机制的第一个真实消费者：Feature 不引用壳插件、不创建菜单控件，只经 `IMenuRegistry` 登记菜单与动作；壳按注册表渲染，因此“新增一个菜单功能”不需要改壳。

## 边界

- 只贡献菜单与关于窗口；不占槽位、不写状态栏、不改壳的菜单结构。
- 关于窗口只读：产品、版本、运行时、操作系统、许可证与版权，没有配置项与交互。
- 不引用任何 Module 工程；`ILocalizationService` 与 `IMenuRegistry` 都从宿主容器解析。
- 文案在插件内部（中英两套），不集中到壳；语言切换由壳重建菜单、窗口自行刷新标签。

## 依赖方向

- 引用 `ImageLyre.Contracts`（本地化）、`ImageLyre.Shell.Contracts`（菜单契约）、cangming 机制包与 Avalonia/AtomUI。
- 被 `ImageLyre.App` 的通配工程引用带进输出目录；不被任何工程按名字引用。

## 边界变化

新增关于项的信息（例如构建哈希、插件清单）先改本节与 `DESIGN-0001` 的菜单贡献说明；若需要命令 Id、快捷键或可用条件，等 G2 的命令注册表落地后再扩，不在本插件里自建第二套菜单机制。
