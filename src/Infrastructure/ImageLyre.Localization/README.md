# ImageLyre.Localization

## 意义

本工程提供界面文案的本地化实现 `LocalizationService`：聚合各插件注册的语句源、维护当前界面语言、缺键时按规则回退并记录诊断、语言切换后向订阅方广播一次事件。它属于宿主基础设施而不是插件，因为欢迎界面在插件系统就绪之前就要显示文案，而本地化失败等于全界面无文案——把它做成可禁用的插件，会让每个插件都要自己声明依赖并处理缺失，代价与收益不成比例。

## 边界（不放什么）

- 不放资源内容：壳与插件各自实现 `ILocalizationSource` 并带自己的卫星程序集，本工程只做聚合与回退；
- 不放界面：不引用 Avalonia、AtomUI、SkiaSharp，也不持有窗口或控件；
- 不放日志实现：诊断通过构造参数里的回调外送，由宿主决定写到哪里，本工程不引用 `Cangming.Logs`；
- 不放插件机制：不引用 `Cangming.PicoPlugins`，它不参与插件扫描，也不出现在插件清单里；
- 不负责语言切换入口：入口属于壳插件，壳只调用 `ILocalizationService`，不拥有机制。

## 依赖方向

引用 `ImageLyre.Contracts`（本地化契约在那里）；被 `ImageLyre.App` 引用（创建实例并交给容器）与 `ImageLyre.Bootstrap` 引用（注册同一实例）。不引用任何插件工程，也不被插件工程引用——插件只依赖契约。

## 边界变化时改哪份文档

先改 `docs/design/lukan/DESIGN-0001-M1-插件骨架.md` §3.1、§5.6 与本文件，再改实现与调用方；若归属从基础设施改为插件，或回退规则变化，先按 `docs/adr/lukan/ADR-0001-插件机制架构基线.md` §2.11 另开 ADR，不允许在实现里顺手改语义。
