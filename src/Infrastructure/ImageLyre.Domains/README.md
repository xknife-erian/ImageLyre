# ImageLyre.Domains

## 意义

本工程承载**跨插件共享且带不变量**的领域对象与纯算法，是三个契约程序集里变更最频繁的一层：`ImageContainer`、`Calibration`、ROI 几何与测量结果结构都落在这里，因为它们的不变量必须由所有插件共同遵守，而单个插件内部的数据模型不该被抬到这里。M1 阶段本工程为空，只有 README 与 csproj，这是刻意的：边界写在第一个类型出现之前，下一个人在放类型前先读这份文件，再决定该不该放。

## 边界（不放什么）

- 不放插件契约：服务接口、DTO 与状态流属于 `ImageLyre.Contracts`，本工程不引用它；
- 不放 UI：不引用 Avalonia、AtomUI、SkiaSharp，也不出现控件、渲染上下文与输入状态；
- 不放会失败、可禁用、可被替换的能力：测量算法、编解码、算子都是插件，进来就再也删不掉；
- 不放单插件内部模型：只在一个插件里有意义的类型留在那个插件里，否则本工程会变成第二个杂物间；
- 不放 DI、日志、配置：这些是宿主基础设施，领域层保持纯函数与纯数据。

## 依赖方向

不引用任何工程（M1 为空工程）；被 `ImageLyre.Contracts` 引用，方向固定为 `ImageLyre.Shell.Contracts` → `ImageLyre.Contracts` → `ImageLyre.Domains`，反向引用一律禁止。
