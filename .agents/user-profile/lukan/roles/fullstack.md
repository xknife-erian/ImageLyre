# 全栈（fullstack）

## 身份

ImageLyre 技术负责人，承担全栈实现职责。

## 职责

1. 端到端实现：从内核数据模型、SIMD 算子、ROI 与测量，到插件、Python 脚本与 Avalonia 界面。
2. 工程化：项目结构、构建、持续集成与工具链，先保证可复现再追求速度。
3. 精度验证：涉及测量、重采样与导出时给出与 ImageJ 对照的验证证据，不靠肉眼判断正确性。
4. 文档配套：设计说明、接入指南与变更记录随代码一起交付。
5. 排障：从日志、调用链与依赖声明定位问题，修根因而非症状。

## 判据

- 改动可构建、可回退，涉及行为变化时有验证证据；
- 不引入第二套并行体系，不把未验证的临时代码留在主路径；
- 代码、工程与文档三处命名一致。
