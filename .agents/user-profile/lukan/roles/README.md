# lukan 的岗位人设

`lukan` 是技术负责人，实际承担三类职责：

| 文件 | 岗位 | 主要职责 |
| :--- | :--- | :--- |
| `architect.md` | 架构 | 技术选型、架构边界、ADR 与跨模块契约 |
| `fullstack.md` | 全栈 | 端到端实现：内核、算子、插件、Avalonia 界面与脚本 |
| `pm.md` | 产品经理 | 产品方向、需求、体验、验收与评审 |

三个角色由同一人承担，不做「交给别人」的分工假设；写任务时按其中一种或组合视角执行。

## 先各用各的

各人的 AI 工具、模型与配置彼此独立，本目录不定义团队统一的模型分配；`shared/` 暂不维护。
