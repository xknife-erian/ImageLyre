# 版式与令牌

本文件是 `html-report` 的细则：A+C 混合视觉（仪器面板的纸感与读数 + 工程图纸的图框与编号）。模板 `templates/review.html` 已按这里的值实现，生成时改内容不改令牌。

## 1. 设计令牌

| 令牌 | 值 | 用途 |
| :--- | :--- | :--- |
| 纸张 | `#F2EEE4` | 文档底色，暖白、低蓝光 |
| 纸张次层 | `#EBE5D6` | 展开详情、引用块、提示底色 |
| 墨色 | `#151515` | 正文、标题、边框 |
| 次级文字 | `#786F5E` | 说明、元信息、表头 |
| 分隔线 | `#D6CDB9` | 表格线、卡片边框 |
| 强调橙 | `#C2410C` | 链接、关键动作、图纸标注 |
| 测量青 | `#0F6E75` | 读数、正向结论、测量值 |
| P1 | `#C92A2A` | 严重问题、报警灯 |
| P2 | `#C77C02` | 一般问题、警示灯 |
| 正文字号 | `15.5px / 1.8` | 中文长读节奏 |
| 标题字号 | H1 `30px`、H2 `30px`、H3 `19px` | 层级靠字重与留白，不靠颜色 |
| 标签字体 | `9.5–11px` 等宽、字距 `.12–.2em` | 铭牌、表头、编号、图注 |
| 纸张宽度 | `≤1180px` | 超过 1200px 一行字太多 |
| 边框 | `1px` 实线，无圆角 | 图纸与仪表面板的硬边 |
| 阴影 | 仅整张纸一层 `0 34px 80px -54px` | 卡片、表格、图框一律不加阴影 |

## 2. 组件

| 组件 | 结构 | 约束 |
| :--- | :--- | :--- |
| 铭牌 `nameplate` | 左项目名（令牌 `{{项目名}}`）+ 文档类型，右 `DOC / REV / PAGE` | 顶部 4px 墨线，等宽小字，不放大段说明 |
| 目录条 `index` | 横向 `01 摘要 / 02 模块 …`，吸附顶部 | 中文 12px 无衬线、编号 10.5px 等宽；章节 ≤12 时单行铺开；超过 12 或放不下时横向滚动，右侧出现“目录 ▾”面板（三列，窄屏一列），当前章节自动滚入视野 |
| 封面区 `hero` | 图框 + 左上/右下角标 + 标题 + 导语 | 只有封面区用图框，正文不再套框，避免整页变重 |
| 规格行 `specrow` | `MODULES 07 / FILES 129 / LINES 11.4k / DATE 11.16` | 上下各一条墨线，数值用等宽字体 |
| 孔位图 `plate` | 12×8 圆孔，P1 红、P2 琥珀、空孔纸色 | 最多 96 项；超过时显示前 96 个并加 `+N`；点击孔位跳到对应条目 |
| 读数 `readout` | 左侧粗墨线 + `FINDINGS` + 大号数字 + 细分 | 数字是页面里最大的元素，只用于总量 |
| 章节号 | `01 / 02 / 03` 幽灵大字，位于标题左侧 | 由 CSS 计数器生成；Markdown 标题里不要再写“一、二、三” |
| 数据表 | 等宽表头、细线行、右对齐数字；生成 `<colgroup>` 并按内容估算列宽 | 表头不做大写转换，代码标识符保持原大小写；列宽合计 100%，配合 `table-layout:fixed`，长代码在单元格内换行 |
| 问题行 | `编号 / 级别 / 模块 / 问题 / 后果` + 展开详情 | 主表只放五列，证据进详情；P1/P2 用描边章，不用色块；筛选按钮 12px 无衬线，选中态用浅底加橙色下划线，不用黑色实底 |
| 图框 `diagram` | 1px 墨框 + 左上/右下角标 + 左上“放大查看”浅底描边按钮（橙色左缘、橙色图标） + `FIG. 0N` 图注 | 页面内按宽度缩放看全貌；点按钮或图框打开原尺寸浮层（可横向滚动，Esc 关闭）；图注 11.5px 无衬线，`FIG` 前缀用等宽 |
| 步骤 | 方形描边序号 `01 / 02` | 不用圆形，不用实心底 |
| 方案卡 `opt` | 1px 边框，推荐项左侧橙色内嵌线 | 推荐标签绝对定位右上角，不挤压标题 |
| 页脚 | 12px 无衬线，来源、日期、资源档 | 必须写明“由 Markdown 生成，勿直接编辑”；路径用等宽，中文不要用等宽小字 |

## 3. 孔位图规则

- 一行 12 孔、共 8 行，固定 96 个位置；孔位按 findings 顺序填充，先 P1 后 P2，空位用纸色。
- 孔位颜色只表达级别：P1 `#C92A2A`，P2 `#C77C02`；不使用第三种颜色区分模块，避免图例过重。
- 孔位是导航：每个孔可点，跳到 `#p1-1` 这类锚点并展开该条（实现时给 `<i>` 包 `<a>` 或加 `data-target`）。
- 分析类默认显示；design/guide/spec 没有台账时删除整块 `overview`，只保留 `specrow`。

## 4. 四体裁骨架

**analyses**：摘要 → 模块/背景 → 业务主线 → 问题台账 → 方案对比 → 结论与遗留。封面区放孔位图与 FINDINGS 读数，台账用五列主表加详情。

**design**：版本表 → 约束 → 结构设计（一张总图，必要时加时序）→ 接口契约（成员、语义、线程安全、生命周期）→ 边界情况 → 变更记录。图框与 FIG 编号在这类文档里用得最多。

**guide**：适用对象 → 前置条件 → 步骤 → 常见问题 → 相关文件。步骤用方形序号，命令用代码块；不生成问题台账。

**spec**：适用范围 → 条款（`S-1` 起）→ 判定清单 → 版本。条款编号用等宽，判定项用方框；每条都要可判定。

## 5. 打印

- A4 纵向、页边距 14mm；纸张转纯白、去点阵底纹，墨线保持黑色。
- 隐藏目录条、筛选工具条、回到顶部；保留铭牌、图框、FIG 编号与章节号。
- 强制展开全部台账详情（`tr.detail[hidden]` 改为 `display: table-row`）。
- 表格行与图框 `break-inside: avoid`，标题 `break-after: avoid`。

## 6. 表格列宽

生成 HTML 时不能把列宽交给浏览器 auto 布局，因为长代码、长说明与短序号列会被平均分配或互相挤压，最后首列只剩一条。正确做法是在每张表前生成 `<colgroup>`，按表头与单元格内容的显示宽度估算比例并把总和归一到 100%，同时给表格加 `table-layout:fixed`；中文与全角符号按 2 个宽度单位计，ASCII 按 1 个计，代码反引号与链接语法不计入。

短列给最小可读宽度而不是按内容压缩：序号列 6–8%，日期列 10–12%，编号/版本列 12–18%，代码类型列 18–24%，其余宽度留给说明列。长代码标识符允许 `overflow-wrap:break-word` 在必要时换行，单元格内换行是排版而不是删信息；生成表格单元格里的代码时，较长代码（约 24 字符以上）在命名空间点与路径斜杠后插入 `<wbr>`，优先在语义边界换行，避免把 `LogService` 切成 `LogServic` 与 `e`；短版本号与方法调用保持原样。表头仍保持原大小写，不做 `text-transform:uppercase`。

生成后必须在 1024px 与 1440px 两个宽度检查：表格不出现横向滚动，首列不被长文本挤成一条，代码列不撑破单元格。`scripts/check-report.ps1` 只检查结构与链接，列宽仍需人工或截图验收，不能因为脚本通过就认为排版合格。

## 7. 反例

| 反例 | 后果 |
| :--- | :--- |
| 圆角卡片 + 投影 + 蓝紫渐变 | 立刻回到“通用 AI 报告”脸，和仪器语境无关 |
| 表头 `text-transform: uppercase` | `JitExpRunnable` 变成 `JITEXPRUNNABLE`，代码标识符不可读 |
| Markdown 标题写“一、二、三”又加章节计数器 | 出现 `04 三、执行阶段` 的双重编号 |
| 推荐标签和标题挤在 flex 两端 | 标题里的 `<code>` 被拆成独立项，版面断裂 |
| 序列图不限制 `max-width` | 图比正文宽，横向溢出或出现滚动条 |
| 每节都套图纸框 | 整页线条过密，长读疲劳，打印费墨 |
| 孔位图满 96 个却只标 37 个有效项 | 读者以为还有 59 个问题没写 |
| 页脚不写资源档 | 断网打开时读者不知道图为什么不见了 |
